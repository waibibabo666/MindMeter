## 二、目的与边界

把 8 个任务的原始行为数据转换成 0–100 的八维参考分，供报告和复测使用。

边界：

- 只做课程演示级计分，**不做临床常模、不做智商换算、不做百分位**；
- 阈值是团队设定的演示参数，不是经过样本验证的常模；
- 同一份作答 + 同一配置版本必须得到同一结果；
- 缺数据时不硬算，明确显示“未测”；
- **不计算总分、均分、综合分**；八个维度独立呈现。

## 三、原始指标

| 维度 | 任务 | 原始指标 | 说明 |
| --- | --- | --- | --- |
| 言语理解 `vc` | 近义词/反义词/句子理解 | `correct`、`total` | 15 题四选一 |
| 言语流畅性 `vf` | 60 秒动物命名（ASR） | `validCount`、`rawText` | 去重后的有效动物名数；`rawText` 只在内存中使用，不落库 |
| 数字运算 `nc` | 两位数加减/简单乘法 | `correct`、`total` | 20 题四选一 |
| 知觉速度 `ps` | 目标符号—四选项匹配 | `correct`、`attempted` | 60 秒内正确匹配数 |
| 归纳推理 `ir` | 数列/字母序列/简单矩阵 | `correct`、`total` | 15 题四选一 |
| 空间视觉化 `sv` | 心理旋转 | `correct`、`total`、`medianRt` | 20 题四选一 |
| 联想记忆 `am` | 12 组词对 + 24 题配对再认 | `hits`、`falseAlarms`、`targets`、`foils` | 12 目标 + 12 干扰 |
| 自然探索 `ni` | 自然图片四选一分类 | `correct`、`total` | 20 张图片 |

## 四、计分公式

统一截断函数：

```text
clamp01(x) = min(1, max(0, x))
```

最终分数为 0–100 的整数。以下阈值全部是演示参数，W5 用户测试后只校准阈值，不改变“非常模、非临床”的定位。

### 4.1 言语理解（vc）

```text
vc = round(100 * correct / 15)
```

### 4.2 言语流畅性（vf）

```text
vf = round(100 * clamp01((validCount - 10) / 20))
// 10 个有效词 → 0 分，30 个 → 100 分
```

- 只计不重复、且属于“动物”类别的词；
- ASR 失败、用户拒绝麦克风、浏览器不支持时，`vf = null`，报告显示“未测”；
- 不提供键盘替代，避免把输入速度混入分数；
- 原始转写文本不写入 `localStorage`。

### 4.3 数字运算（nc）

```text
nc = round(100 * correct / 20)
```

### 4.4 知觉速度（ps）

```text
ps = round(100 * clamp01((correct - 20) / 40))
// 20 个正确匹配 → 0 分，60 个 → 100 分
```

### 4.5 归纳推理（ir）

```text
ir = round(100 * correct / 15)
```

### 4.6 空间视觉化（sv）

```text
accScore = clamp01(correct / 20)
rtScore  = clamp01((5000 - medianRt) / 3000)   // 5000ms → 0，2000ms → 1
sv       = round(100 * (0.7 * accScore + 0.3 * rtScore))
```

- `medianRt` 只统计正确试次；
- 反应时 <200ms 或 >3× 该被试中位数的试次视为异常，不进入中位数；
- 正确试次不足 10 个时，`sv = null`。

### 4.7 联想记忆（am）

```text
H = (hits + 0.5) / (targets + 1)          // targets = 12
F = (falseAlarms + 0.5) / (foils + 1)     // foils = 12
d' = z(H) - z(F)                          // z 为标准正态分位数
am = round(100 * clamp01((d' + 1) / 5))   // d' = -1 → 0，d' = 4 → 100
```

### 4.8 自然探索（ni）

```text
ni = round(100 * correct / 20)
```

## 五、异常与缺失

- 某个任务完成试次不足 80%：该维度为 `null`，报告显示“未测”；
- 未完成的任务（快测/标准未包含的维度）：`null`，不按 0 分；
- 言语流畅性 ASR 失败：`vf = null`；
- 空间视觉化异常试次：<200ms 或 >3× 中位数，剔除后不足 10 个正确试次则 `null`；
- 所有分数截断到 0–100 的整数，不人为压到 5–98；
- 不静默插补、不用均值替代缺失维度；
- 配置版本写入每条记录。

## 七、报告中的呈现

- 八个维度各自显示 0–100 参考分；`null` 显示“未测”；
- **不显示总分、均分、综合分、智商、脑龄、百分位、误差范围**；
- 雷达图八轴；未测维度留空，不画 0；
- 维度解释只描述本次任务表现，不做人格、疾病、能力类型推断；
- 固定声明：“课程演示参考分，非常模、非临床、无人群比较”；
- 复测只比较两次都测过的共同维度，提示“变化不等于训练效果”。

## 八、局限

- 没有中文常模，分数只代表本次任务表现，不能读成“超过多少人”；
- 8 项是产品口径，不是学界公认的“8 种智力”；自然探索智能来自多元智能理论，不是 CHC 常规维度；
- 本期不测工作记忆、抑制控制、认知灵活性，报告必须写明；
- 练习效应、设备差异、睡眠和情绪都会影响结果；
- 复测变化不等于训练效果，报告必须提示“相关不等于因果”；
- W5 只校准阈值，不改变“非临床”定位。
