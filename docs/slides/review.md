# 幻灯片工作 Loop：制作 → 内容审核 → 评分

> 适用对象：`docs/slides/slides.md`（面向《创新工程实践营》项目汇报，8 分钟产品介绍 + 2 分钟演示 + 5 分钟答辩）。
> 原则：**严格按参考文档的章节编号与要求**；需要截图的一律留占位，由作者本人提供，不得用编造内容或代替图充数。

## 一、Loop 三步

```text
① 制作（写 / 改）
   ↓
② 内容审核（逐条对照参考文档）
   ↓
③ 评分（自动 + 人工），不达标回到 ①
```

### ① 制作

- 只改 `docs/slides/slides.md` 与 `docs/slides/style.css`；
- 每页只放一个论点；表格 ≤ 6 行；正文 ≤ 300 汉字（审计脚本会算）；
- 章节标题严格使用参考文档编号（1.1.1 … 3.7.2），补充页用「3.5.3（续）」而非新编号；
- 涉及截图的位置写占位块（见第三节），不写“示意图”冒充。

### ③ 评分（满分 100，< 85 回炉）

| 维度 | 分值 | 判定方式 |
| --- | --- | --- |
| 结构完整 | 30 | 参考文档 23 个条目是否都有对应页（脚本 A 项） |
| 编号一致 | 15 | 标题编号与参考文档一致、无跳号、补充页用「（续）」（脚本 B 项） |
| 信息密度 | 20 | 每页正文 ≤ 300 汉字、表格 ≤ 6 行（脚本 C 项） |
| 截图占位 | 20 | 4 处必填占位齐全且写明截图内容（脚本 D 项） |
| 来源与口径 | 10 | 引用来源、非诊断等边界声明（人工） |
| 时长匹配 | 5 | 演讲备注覆盖 8 + 2 + 5 分钟（人工） |

## 二、截图占位规范

占位块写法（不要用假图）：

```html
<div class="shot">
  <div class="shot-head">截图占位 · 3.3 提交历史</div>
  <p>请拍：GitHub → Insights → Pulse（或 Contributors），显示每位成员提交次数</p>
  <p class="shot-file">建议放在：docs/slides/images/pulse.png</p>
</div>
```

拿到截图后：把文件放进 `docs/slides/images/`，再把占位块整块替换为
`<img src="/images/pulse.png" class="shot-img" />`。
