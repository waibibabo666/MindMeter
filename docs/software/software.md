Web 前端 ──HTTPS──> API 网关 / Backend ──> Core Engine（计分）

                         ├─ PostgreSQL          └─ 量表/常模版本库
                         ├─ Redis（会话/限流）
                         └─ 对象存储（报告/导出）

## 2. 模块划分

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| Frontend | 测评交互、报告展示 | Backend API |
| Backend | 账号、会话、权限、报告、订阅 | Core Engine、DB |
| Core Engine | 计分、效度、常模、版本 | 量表数据 |
| Admin | 题库、常模、内容、看板 | Backend |
| Ops | 监控、日志、备份、告警 | 全部 |
