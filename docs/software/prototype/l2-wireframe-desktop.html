四级断点（按组长方案）

同一套 DOM，CSS Grid 换列；信息层级不重排、只折叠。E2E 保留 1440×900 与 360×800 两套截图。

≥ 1200px · 三栏
  • 侧栏 232px + 主区 1fr（≤960）+ 右栏 340px
  • 右栏放摘要 / 引用 / 快捷操作
900–1199px · 两栏
  • 右侧上下文栏折叠进主区底部
  • 侧栏收窄到 200px
600–899px · 单栏
  • 侧栏变为顶部横向导航
  • 报告双栏退回上下堆叠
< 600px · 手机单栏
  • 即已合并的移动版线框（l2-wireframe.html）
  • 360px = 回归底线：触控 44px、无横向滚动
实施顺序：app shell 三栏 → 首页/报告/趋势桌面化 → 对话三栏 → 设置/记忆两栏 → 补 900/600 断点 → E2E 双尺寸截图。禁止"把 620px 改成 1200px"冒充桌面版。
