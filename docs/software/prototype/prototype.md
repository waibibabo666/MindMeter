# MindMeter 交互原型 v5（八维 / 三档骨架）

单文件前端原型，零依赖，双击 `index.html` 即可运行。

> v5 是**骨架**：三档流程、8 个任务入口、八维报告、历史、设置（BYOK/ASR）可走通；任务内部暂用演示/占位逻辑，不代表最终计分实现。正式实现落到 `code/`。

## 目录

```text
prototype/
├─ index.html           原型骨架（零依赖）
├─ prototype.md         本文件：三档、任务、原型状态与改动入口
├─ agent-接入位.md      BYOK AI 的接入契约、开关位置、降级规则
└─ 页面流程图v4_legacy.png  旧版流程图（含 8 游戏旧方案，仅参考；v5 以 index.html 为准）
```

## 运行

直接双击 `index.html`。无需构建、无需安装、无需联网。
AI 和 ASR 需要网络/麦克风，默认关闭。

## 三种测评模式

| | 快测 | 标准 | 深度 |
| --- | --- | --- | --- |
| 时长 | ≈ 5 分钟 | ≈ 13 分钟 | ≈ 28 分钟 |
| 任务数 | 2 | 4 | 8 |
| 包含 | 知觉速度、言语流畅性 | 言语理解、知觉速度、空间视觉化、联想记忆 | 全部 8 项 |
| 适用 | 先看两项 | 看四项结构 | 看完整八维 |

**设计原则：高档位只「加任务」，不改已测任务的核心参数。** 但三档没有共同的一套四项，因此：

- **不设总分/均分**；
- 跨档只比较共同维度（快测与标准只有“知觉速度”共同）；
- 扩展维度只做个体纵向比较，不出人群百分位。

## 八个任务

| 顺序 | 维度 | 任务 | 参数 | 指标 |
| --- | --- | --- | --- | --- |
| 1 | 言语理解 | 近义词/反义词/句子理解四选一 | 15 题 / 3 分钟 | 正确数 |
| 2 | 数字运算 | 两位数加减/简单乘法四选一 | 20 题 / 3 分钟 | 正确数 |
| 3 | 归纳推理 | 数列/字母序列/简单矩阵四选一 | 15 题 / 5 分钟 | 正确数 |
| 4 | 知觉速度 | 目标符号—四选项匹配 | 60 秒 | 正确匹配数 |
| 5 | 空间视觉化 | 心理旋转四选一 | 20 题 / 3 分钟 | 正确数、中位反应时 |
| 6 | 联想记忆 | 12 组词对 + 24 题配对再认 | 学习 30 秒 + 3 分钟 | 命中、虚报 |
| 7 | 自然探索 | 自然图片四选一分类 | 20 题 / 3 分钟 | 正确数 |
| 8 | 言语流畅性 | 60 秒动物命名（ASR） | 60 秒 | 有效词数 |

任务开始前有 1–2 次练习，练习不计分；正式试次不显示对错。

## 四款补充练习

心算连击 / 舒尔特方格 / 翻牌配对 / 快速分类

- 不计分、不进报告、不进雷达图；
- 最佳纪录按「游戏 × 难度」存 `mindmeter.practice.v1`；
- 时间不够可整体延期（P2）。

## 两个入口

| | 完整测评 | 补充练习 |
| --- | --- | --- |
| 顺序 | 锁定 | 任意 |
| 反馈 | 正式试次无对错 | 即时 |
| 成绩 | 进八维报告 | 不进报告 |
| 可重复 | 否 | 是 |

## 设置

| 项 | 说明 |
| --- | --- |
| AI 开关 | 默认关闭；开启前必须填 endpoint/model/key |
| endpoint | OpenAI-compatible `/chat/completions`，必须支持浏览器 CORS |
| API Key | 只存本机 `mindmeter.settings.v1`；可一键清除；公用设备提示 |
| ASR | 仅 Chrome/Edge 的 Web Speech API；不支持时快测不可用，深度档该维度记“未测” |
| 数据清除 | 删除 sessions/draft/settings（含 Key）/practice |

## 改动入口

| 想改什么 | 位置 |
| --- | --- |
| 三档各含哪些任务 | `MODE_CFG` 的 `tasks` 数组 |
| 任务顺序/题量/时长 | `TASKS` 配置对象 |
| 计分公式 | `core_engine`（正式）或原型 `completeDemoTask()`（演示） |
| 建议文案 | `ADVICE` |
| AI 接入 | `settings`（`enabled: false` 即关闭） |
| 维度名称 | `DIMS`、`DIM` |
| 主题色 | CSS `:root` 的 `--accent`、`--accent2` |

## 已知限制

- 原型任务为骨架/演示逻辑，**不是最终计分实现**；
- 4 款补充练习在骨架中只留入口，游戏逻辑和最佳纪录待接入；
- 8 项分数为 0–100 参考分，**没有人群常模**，不能当百分位；
- 不设总分、不做百分位、不给误差范围；
- 本期不测工作记忆、抑制控制、认知灵活性；
- ASR 仅 Chrome/Edge；无键盘替代；
- AI 为 BYOK，需要用户自己的 endpoint/model/key，且 endpoint 必须支持 CORS；
- 数据存 `localStorage`，换浏览器即丢失；
- `页面流程图v4_legacy.png` 是旧图（含 8 游戏旧方案），v5 以 `index.html` 为准。
