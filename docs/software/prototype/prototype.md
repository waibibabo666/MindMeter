# MindMeter 交互原型 v3

单文件前端原型，零依赖，双击 `index.html` 即可运行。

## 目录

```
prototype/
├─ index.html           原型本体（1597 行，零依赖）
├─ agent-接入位.md      AI 教练的接入契约、开关位置、降级规则
├─ 维度依据调研.md      四维度依据、信度现实、scoring-v2 计分改造
└─ 页面流程图v3.png     页面结构与跳转关系
```

## 运行

直接双击 `index.html`。无需构建、无需安装、无需联网。

可选：如需调试建议接口，在仓库根目录另起后端服务（`server.py` 若已落地），
把 `index.html` 里的 `AGENT.endpoint` 指向该服务即可。

## 说明

本目录是**交互原型**，不是产品实现：

- 不参与构建，不被 `code/` 引用
- 数据存浏览器 `localStorage`，不做服务端持久化
- 分数为 0–100 参考分，**没有人群常模**，不能当百分位使用

## 四个测评任务

| 顺序 | 任务 | 构念 | 参数 | 指标 |
| --- | --- | --- | --- | --- |
| 1 | 词语编码 | — | 16 词，8 秒 | — |
| 2 | Corsi 序列广度 | 视空间工作记忆 | 长度 3→7 自适应 | 广度、正确率 |
| 3 | Go / No-Go | 抑制控制 | 60 试次，25% No-Go | Go 正确率、commission rate |
| 4 | 简单反应时 | 反应速度 | 30 试次 | 中位数、IQR |
| 5 | 词语再认 | 词语再认 | 16 旧 + 16 新 | d′ |

第 2–4 步天然充当记忆干扰，第 5 步测的是延迟再认。

## 八款练习游戏

翻牌配对 / 舒尔特方格 / 节奏点击 / 心算连击 /
反向指令 / 记忆序列 / 快速分类 / 点数闪现

各 3 档难度，最佳纪录按「游戏 × 难度」存储。

## 两个入口

| | 完整测评 | 游戏中心 |
| --- | --- | --- |
| 顺序 | 锁定 | 任意 |
| 反馈 | 无 | 即时 |
| 成绩 | 进画像 | 不进画像 |
| 可重复 | 否 | 是 |

## 改动入口

| 想改什么 | 位置 |
| --- | --- |
| 试次数、刺激时长 | 各 `runCorsi` / `runGoNoGo` / `runSRT` 开头的常量 |
| 计分公式 | 各任务的 `finish()` |
| 建议文案 | `const ADVICE` |
| AI 接入 | `const AGENT`（`enabled: false` 即关闭） |
| 维度名称 | `DIM_CN`、`DIM_SHORT` |
| 主题色 | CSS `:root` 里的 `--accent`、`--accent2` |

## 已知限制

- 分数为 0–100 参考分，**没有人群常模**，不能当百分位
- 数据存 `localStorage`，换浏览器即丢失
- AI 教练仅留接入位，当前使用本地规则文案
- 部分试次低于文献常规（Go/No-Go 60 次 vs 100+）
- 未做移动端手势适配与无障碍
