# ADR-0002：非临床定位与 Agent 语言契约（MoCA 参考范围）

- 状态：提议（Proposed，待评审）
- 日期：2026-11-14

- 外部参考：[ADI 对 MoCA-XpressO 的案例研究](https://www.alzint.org/news-events/news/encouraging-earlier-conversations-about-brain-health-a-case-study-on-moca-xpresso/)、[XpressO 验证论文（JAGS 2024）](https://pubmed.ncbi.nlm.nih.gov/38558263/)

## 背景

面向普通人的认知平台，最大风险不是技术不够先进，而是**用临床工具的语言制造出产品并不具备的诊断权威**。行业对照：MoCA-XpressO 上线以来 15 万+ 次自评、>85% 认为有帮助，其公开定位刻意克制（"不替代临床评估，帮助你反思并开启与专业人员的对话"），但它的权威仍然继承临床 MoCA——红分信号、分数分布呼应 MCI 患病率、CHAI 概率话术、漏斗指向就医。这留下一个尚未被占据的位置：**临床漏斗之外、娱乐测验之上的"诚实自我监测"层**——八维结构化框架 + Agent 如实呈现"分数能说明什么、不能说明什么" + 把认知表现解释为可动的结构性条件而非归罪。

团队同时提出"参考 MoCA 的维度与测评方式作为科学依据、提高可信度"，需要与既有红线（不设总分、无常模、不做百分位、不提供诊断/用药/就医建议，见 [rengzhi.md:75](../research/rengzhi.md) 与 README）明确关系，防止"参考"被读成"采用其量表体系"。

本决策的全部落点在 **Agent 模块**：定位只有变成 agent 的措辞、校验与兜底行为，才是可执行、可验收的产品事实。

## 决策

1. **MoCA 关系三分法**：维度**框架**参考 MoCA 的认知域覆盖（广度依据）；任务**形式**沿用各领域经典范式（言语流畅 FAS/动物命名、数字符号替换、心理旋转、词表延迟回忆与再认、系列减 7 等——效度依据在范式层）；**分数体系**自建（自我基线、非常模、无总分）。对外禁止"以 MoCA 为科学依据"的表述；允许"借鉴其域框架组织测评广度，分数只与自己的历史比较"。
2. **两处坦率例外**：自然探索（ni）无 MoCA 对应域，依据表述为分类归纳/语义知识范式，不挂靠 MoCA；定向力（时间/地点）有意不做——它是识别意识障碍的临床项，理由随知识库对外解释。
3. **不借临床权威**：不做红黄绿信号、cutoff、风险概率话术；分数不得换算成任何量表分值；就医引导只保留危机/越界两条固定话术作为窄桥，不设计"引导就医"主路径。
4. **Agent 语言契约**（同时约束 AI 输出、UI 文案与宣传材料）：对外措辞"监测→回看/长期记录"、"评估→自测/参考分"；禁用临床演进词（减退/受损/退化加入 `BANNED_WORDS`）；禁止一切特质归因——正负皆禁（"很有天赋""太笨"同规则）；解释只指向可动条件（状态/策略/任务设计/情境/测量局限），使"条件"是行动入口而非免责出口。
5. **声明边界一等对象**：每维度元数据携带 `claims`（能说明/不能说明）；Agent 回答在场景策略中要求包含至少一条"不能说明"句（软校验，见 P0 设计文档 §5.1）；报告模板与趋势模板天然满足（现有 `CLOSINGS`/练习效应提醒）。
6. **自责重导向**：命中"第一人称 × 贬义特质"模式（我太笨/脑子不行/我就是没用）→ 固定话术，把评价转回本次任务条件并邀请点名单个维度展开。归类为**结果解释**动作，不进入心理疏导（维持 MM-REQ-007 §十五 不做情绪支持的边界）；安全词优先级不变（crisis/boundary 恒先）。
7. **可信度叙事=透明性**：对"没有常模还有什么用"给出标准答案——计算全披露（scoring-v3.1 可复现）、自我基线可比、条件与局限明说、AI 只解释不判读；随知识库 `limit`/`score` 块对外。
8. **Agent 北极星指标**：成功度量从"答得准"改为"反思与开启对话的质量"——多轮追问深度、回访复测间隔（≥7 天纪律）、对话后一个轻量自评问。本条只定口径，埋点与报表属 M3。

## 后果

- P0 改造包设计文档同步修订（策略表加 `require_scope_note`；classify 加自责模式；趋势/解释场景 prompt 加"禁止换算与特质归因"纪律）。
- 知识库增补一批（约 12–16 块）：MoCA 域映射、"能否换算"边界、条件五件套（状态/策略/任务设计/情境/测量局限）、透明性标准答案；全部走审核门禁置 `reviewed`，配套评测查询用例。
- 评测集新增两组用例：量表换算拒绝、自责重导向；现有 legacy 30 条保持绿。
- 界面与 README 文案需按语言契约过一遍（如"长期监测"表述）；两份调研文档保留原文作历史，不重写。
- Agent 校验器的既有 fail-closed 结构不变：本 ADR 只扩词表与话术分支，不放宽任何安全优先级。

## 不采用

- 直接嵌入标准 MoCA 计分（30 分总分、26 cutoff、教育校正）：与"不设总分、无常模"红线冲突，且对健康人群有天花板效应（调研已记录）；
- 仿 XpressO 增加红分信号或"就医漏斗"主路径：借用临床权威，正是本 ADR 要防的失败模式；
- 给 Agent 增加共情/疏导模式：越出 §十五 边界；自责场景只做解释重导向；
- 把 MoCA 题目原文成段录入知识库（版权风险，仅允许构念层面的解释）。

## 验收

- 本文状态改为"已接受"且 P0 设计文档补丁合入后，才算定位生效；
- 抽查 10 类提问（含换算、自责、"我是不是有病"、"和 MoCA 比怎么样"）的 agent 输出：0 临床判读词、0 换算数字、0 特质归因；
- 知识库增补块全部 `reviewed` 且在检索评测查询中 hit@3 ≥80%。
