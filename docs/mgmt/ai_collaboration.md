> 四个人都有 vibe coding 工具，不代表任务变成“让 AI 写完”。AI 降低的是**打字和样板代码成本**，不降低**判断、审查、验证、集成、安全与责任**。本文件把任务重构成人真正要做的事。

## 二、核心判断

1. **任务单位变了**：从“写 Auth”变成“定义 Auth 契约 → 让 AI 生成 → 审 diff → 跑测试/手工验证 → 集成 → 留证据”。
2. **人保留四类工作**：决策（做什么/不做什么）、上下文（给 AI 什么）、审查（对不对/安不安全）、验收（能不能交付）。
3. **AI 适合初稿**：脚手架、CRUD、页面、测试、文档、迁移、脚本、prompt、Issue 正文。
4. **AI 不适合最终责任**：密钥、生产凭据、真实用户数据、authz、计分语义、医学/伦理措辞、发布批准。
5. **不要用 AI 生成速度压缩验收**：生成快了，review/测试/返工仍是人的主成本。

| **P** | 人机配对，AI 生成，人设计/调试/验收 | 后端接口、前端页面、Agent 节点、RAG 管道、CI | 写 brief、审 diff、跑测试、手工验证 |

| **X** | 不应交给 AI | 生产 Key、真实用户数据、最终诊断/治疗表述、发布批准 | 人独立完成/批准 |

## 四、标准协作循环（每个任务都走）

```text
1. 人写任务 brief（10–20 分钟）
   目标 / 上下文文件 / 约束 / 验收 / 例子 / 不要做什么
        ↓
2. AI 生成初稿（代码 + 测试 + 说明）
        ↓
3. 人 review diff（架构、authz、边界、错误处理、依赖）
        ↓
4. 人跑自动测试 + 手工验证（curl/浏览器/DB/日志）
        ↓
5. 人集成（合并、迁移、环境、CI）
        ↓
6. 人留证据（命令、截图、评测结果），更新任务/文档
```

> 一个人不要让 AI 生成后“看起来能跑”就合并；至少另一个人看 diff，auth/Key/计分必须 2 人。

| 后端/API | FastAPI 路由、CRUD、Pydantic、测试骨架 | authz、事务、迁移、限流、错误语义、手工 API 验证 | 生产 Key、权限模型最终决定 |

## 六、关键任务的人机分工卡

### P-02 API 契约 v1

- **人先做**：定资源、状态码、错误格式、分页、幂等、authz 边界；决定哪些字段绝不返回。
- **AI 初稿**：OpenAPI YAML、Pydantic skeleton、示例请求。
- **人验收**：逐条对照功能需求；检查 IDOR/越权/404/429；确认无 Key/密码字段。
- **证据**：OpenAPI 文件 + 契约测试 + review 记录。

### BE-03 Auth

- **人先做**：威胁模型（撞库、枚举、refresh 轮换、登出、限流）。
- **AI 初稿**：路由、argon2、JWT、refresh 表、测试。
- **人验收**：手工跑注册/登录/刷新/登出；检查 token 不进 URL/日志；失败限流；密码重置策略。
- **不能外包**：最终 authz 规则、密钥管理。

### BE-05 Assessment submit

- **人先做**：状态机（created/in_progress/submitted/scored）、幂等键、draft 过期。
- **AI 初稿**：CRUD、schema、测试。
- **人验收**：重复提交同结果；部分提交；越权；draft 恢复；无 total 字段。
- **证据**：pytest + curl + DB 查询。

### AS-01 计分公式

- **人先做**：8 维语义、缺失规则、阈值、版本；手算 5 组金标准。
- **AI 初稿**：公式、配置、单测。
- **人验收**：逐组手算对照；边界 0/100；缺失 null；确认没有总分。
- **不能外包**：公式语义和“非常模/非临床”边界。

### RG-02 Embedding/ingest

- **人先做**：语料来源、版权、切块、元数据、版本。
- **AI 初稿**：embedding 脚本、pgvector 表、重建命令。
- **人验收**：重建可重复；source 正确；无未审内容；检索样例。
- **不能外包**：知识库内容审核。

### AG-04 Validate 节点

- **人先做**：禁用词表、数字来源规则、建议 ID 白名单、长度、引用要求。
- **AI 初稿**：校验节点、单测。
- **人验收**：30 条 red-team；编造数字/越界/无引用必须回退；删除记忆后不引用。
- **不能外包**：安全边界和最终拒答话术。

### FE-05 对话 UI

- **人先做**：信息层级、引用展示、建议卡、空/错/降级状态、移动端。
- **AI 初稿**：消息列表、卡片、样式。
- **人验收**：360px、键盘、无总分、无 Key、引用可读、降级不空白。
- **不能外包**：UX 判断和文案。

### QA-02 E2E

- **人先做**：关键路径和失败路径清单。
- **AI 初稿**：Playwright 脚本。
- **人验收**：真实跑；看截图/视频；判断 flaky；修选择器。
- **不能外包**：发布前人工走查。

### OPS-02 部署

- **人先做**：域名、HTTPS、DB、环境变量、备份、回滚。
- **AI 初稿**：Docker/CI/部署脚本。
- **人验收**：部署一次、回滚一次、恢复一次；日志无 Key/PII。
- **不能外包**：生产密钥、发布批准。

## 七、AI 产出审查清单

### 代码

- [ ] 测试真的跑过，不是“生成即通过”；
- [ ] 没有硬编码 Key/密码/真实数据；
- [ ] authz 按 user_id 校验，越权 404；
- [ ] 输入校验、SQL 参数化、错误不回堆栈；
- [ ] 依赖锁定、许可证可接受；
- [ ] 没有死代码/假实现/TODO 冒充完成；
- [ ] 迁移可回退。

### 产品/文案

- [ ] 不出现总分、常模、百分位、误差范围；
- [ ] 不出现诊断/治疗/疗效/提升智商；
- [ ] 不收集姓名/手机号/年龄/学历；
- [ ] 建议来自固定库，不新增方法；
- [ ] 引用/局限/免责声明在。

### Agent

- [ ] 数字来自 facts；
- [ ] 禁用词 0；
- [ ] 引用 ≥1（有知识块时）；
- [ ] 失败回退模板；
- [ ] 删除记忆后不引用；
- [ ] 危机/越界走固定话术。

### UI

- [ ] 360px 无横向滚动；
- [ ] 键盘可完成关键路径；
- [ ] 空/错/加载/降级状态都有；
- [ ] 不显示 Key；
- [ ] 对比度/非颜色表达。

### Ops

- [ ] `.env` 不入库；
- [ ] 日志脱敏；
- [ ] 备份/恢复演练；
- [ ] 回滚步骤可执行；
- [ ] 限流/告警生效。

## 九、每日/每任务节奏

- **早上 15 分钟**：选 1–2 张卡，写 brief/上下文，确认依赖；
- **上午**：AI 生成初稿，人同步审 diff；
- **下午**：跑测试/手工验证/集成，更新文档；
- **收工前**：CI 绿、任务卡留证据、把 AI 失败案例记到复盘；
- **每周**：抽 1 个任务做“无 AI 复核”，防止团队失去判断力。

## 十、估算怎么改

- 原 [任务拆分](task_breakdown.md) 的 70.5 人日 **按人的投入计**，不是 AI 打字时间；
- AI 会减少样板代码/测试/文档时间，但 review、手工验证、集成、返工会吃掉一部分；
- **不要先按“AI 快 3 倍”压缩排期**；先按原估算排，记录每个任务的实际人时，第一个迭代后再校准；
- 估算记录建议：`brief 分钟 / AI 生成分钟 / review 分钟 / 测试分钟 / 返工分钟`。

## 十二、明确不交给 AI

- 生产 API Key、数据库密码、域名/证书私钥；
- 真实用户数据、完整对话、ASR 音频；
- 最终诊断/治疗/危机话术；
- 最终 authz/权限模型；
- 发布批准、回滚决定；
- 计分公式语义的最终判断。
