> 一句话：M1 是一条**纯本地、无远端登录**的纵向切片——打开即用 → 标准 4 项 → 本地计分 → 八维报告（4 项已测、4 项未测）→ 用户配置自己的 LLM API → Agent 解释/建议/追问 → 本地记忆/摘要 → 本地复测趋势。
>
> **不做远端账号、JWT、FastAPI/Postgres/pgvector、服务端 LangGraph、服务端存储；不做快测/深度/8 项/ASR/练习。**

## 二、M1 用户旅程

1. 打开静态页面，阅读 18+ / 非诊断 / 本地存储 / LLM API 使用说明；
2. 直接开始标准档（不登录、不显示快测/深度入口）；
3. 完成标准 4 项：言语理解、知觉速度、空间视觉化、联想记忆；每项前 1–2 次练习；
4. 浏览器本地计分，生成八维报告：4 项分数 + 4 项“未测”，八轴雷达，无总分；
5. 在设置里填自己的 LLM endpoint / model / key（BYOK），开启 Agent；
6. Agent 解释最低维度、给 2–3 条建议、回答追问，引用 facts + 本地知识块；
7. 会话结束写本地摘要；可查看/编辑/删除本地画像与记忆；
8. 7 天后（或第二次测评后）查看本地共同维度趋势，Agent 解释变化；
9. 导出本地 JSON、清除本地数据；不需要注销账号。

## 三、M1 范围内

| 能力 | M1 做到什么 | 验收 |
| --- | --- | --- |
| 入口 | 静态页面，打开即用；无注册/登录 | 断网可打开页面（LLM 除外）；无账号接口 |
| 同意 | 18+、非诊断、本地存储、LLM API 使用四项 | 未勾选不能开始；不收集姓名/手机号/年龄/学历 |
| 标准 4 项 | 言语理解、知觉速度、空间视觉化、联想记忆；1–2 次练习；本地 draft | 只提交给本地计分；刷新可从当前任务说明页重开 |
| 本地计分 | 浏览器 `scoring-v3`；M1 用 4 维；缺失 null | 金标准一致；无总分/常模/百分位 |
| 八维报告 | 8 轴雷达；4 项分数 + 4 项“未测”；2–3 条建议；局限 | 无总分；固定免责声明；360px 可用 |
| 本地 Agent | 报告解读、追问、趋势解释；用户自备 LLM API；状态机；模板兜底 | 引用 facts/本地知识块；禁用词 0；幻觉数字 0 |
| 本地记忆 | 最近 20 条消息、画像、测评摘要、建议记录 | 可查看/编辑/删除；删除后不再引用 |
| 本地 RAG | 30 条知识块 JSON、关键词/BM25 检索 top3、引用 | hit@3 ≥80%；引用可读；无未审内容 |
| 本地趋势 | 两次测评共同维度差值；7 天提示 | 只比共同维度；无总分；不判断进步/退步 |
| 数据权利 | 导出本地 JSON；清除全部本地数据 | 导出不含 Key；清除后不可恢复 |
| 工程 | 静态托管；浏览器测试；docs/prototype CI | 无后端也可运行；CI 全绿 |

## 四、M1 明确不做

- 远端账号/登录/JWT/邮箱验证/密码找回；
- FastAPI/Postgres/pgvector/服务端 LangGraph/服务端 Key 托管；
- 快测 2 项、深度 8 项、ASR 言语流畅性、4 款练习；
- SSE 流式、公开分享、社区、排行榜、B 端、付费、原生 App、多语言；
- 常模/百分位/误差范围/总分、诊断、7 天计划/打卡、情绪支持；
- 跨设备同步、服务端 30 天删除任务。

## 五、M1 验收标准（G2 出口）

### 5.1 功能

- [ ] 打开页面→同意→标准 4 项→本地报告→配置 LLM→对话→摘要→第二次测评→本地趋势，全链路可走通；
- [ ] 报告显示 4 项分数 + 4 项“未测”，八轴雷达，无总分；
- [ ] 刷新后已完成任务保留，当前任务从说明页重开；
- [ ] Agent 能引用当前 facts 和至少 1 个本地知识块；无事实/无检索时明确说“不知道”；
- [ ] 删除本地记忆后，后续回答不再引用；
- [ ] 导出 JSON 不含 LLM Key；清除数据后页面/历史为空；
- [ ] 未配置 LLM API 时，报告和模板解释仍完整。

### 5.2 质量

- [ ] 本地计分金标准：正常/边界/缺失全绿；
- [ ] Agent 30 条评测：准确/有依据/有用/无越界各 ≥4/5；禁用词 0；幻觉数字 0；
- [ ] 本地 RAG 20 条检索：hit@3 ≥80%；
- [ ] 首屏 ≤3s；任务输入反馈 ≤100ms；本地计分 ≤100ms；AI 完整 ≤30s，超时模板 ≤2s；
- [ ] 360px 可用；关键路径键盘可完成；无阻断控制台错误；
- [ ] Key 只存本机，不出现在日志/导出/页面源码；
- [ ] CI（docs/prototype/security）全绿；无后端 job 依赖。

### 5.3 证据

- 测试命令与结果、原型 smoke 结果；
- 5 分钟演示录屏/截图（打开→标准 4 项→报告→配置 LLM→对话→趋势）；
- Agent 评测表、本地 RAG hit@3 表；
- 导出样例（脱敏）、清除数据验证记录。

## 七、依赖与风险

| 项 | 说明 | 处理 |
| --- | --- | --- |
| LLM API CORS | 用户 endpoint 可能不允许浏览器直连 | 设置页提示；失败回退模板；不提供代理 |
| 本地存储上限 | localStorage 约 5MB | 只留 20 条 + 摘要；超出提示导出/清理 |
| Key 本机存储 | XSS/公用设备风险 | 页面警告；可一键清除；不写日志/导出 |
| 跨设备 | 无同步 | 导出/导入 JSON（M1 可只做导出） |
| 本地计分可改 | 浏览器数据可被用户修改 | M1 是本地演示/自用，不做防作弊；L2 再服务端计分 |
| RAG 质量 | 关键词/BM25 语义弱 | 30 条精编；hit@3；检索不到说“不知道” |
| 无服务端删除 | 清除即本地删除 | 明示“不可恢复”；不做 30 天保留 |
| M2/M3 迁移 | 以后可能加账号/服务端 | 数据 schema 预留 `schemaVersion`；不承诺自动迁移 |
