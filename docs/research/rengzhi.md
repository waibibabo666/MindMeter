## 0. 一句话前提
**「认知水平」不是一个数，而是一组相对独立的维度。** 任何把它压缩成单一分数的做法，都会丢掉大部分信息，也最容易在科学性上被质疑。
这句话决定了三件事：
1. 产品输出必须是**多维画像**，不是总分
2. 每个维度必须**独立测量**，不能由一个游戏推断全部
3. 报告必须给出**相对位置和误差范围**，不能只给一个绝对分

## 1. 测什么：构念框架
### 1.1 CHC 理论（学术界主流）
Cattell–Horn–Carroll 理论是目前智力研究最广泛接受的分类框架：
| 构念 | 英文 | 通俗描述 | 可训练性 |
| --- | --- | --- | --- |
| **Gf** 流体推理 | Fluid Reasoning | 面对新问题时推理、找规律 | 弱 |
| **Gc** 晶体智力 | Crystallized Intelligence | 词汇、常识、经验积累 | 强（依赖学习） |
| **Gwm** 工作记忆 | Working Memory | 同时保持并操作多条信息 | 有一定空间 |
| **Gs** 加工速度 | Processing Speed | 处理信息的快慢 | 有一定空间 |
| **Gsm** 短时记忆 | Short-term Memory | 一次性保持的信息量 | 有限 |
| **Gv** 视空间 | Visual-Spatial | 空间想象、图形旋转 | 有限 |
| **Glr** 长时存储与提取 | Long-term Storage & Retrieval | 记忆存储与提取效率 | 有限 |
| **Gt** 决策速度 | Decision Speed | 简单反应的快慢 | 稳定 |
| **Ga** 听觉加工 | Auditory Processing | 声音辨别与编码 | 有限 |
### 1.2 临床神经心理学维度（另一套切法）
| 维度 | 覆盖内容 |
| --- | --- |
| 注意 | 持续注意、选择性注意、分配注意 |
| 记忆 | 即时回忆、延迟回忆、再认 |
| 执行功能 | 抑制控制、认知灵活性、计划 |
| 语言 | 命名、流畅性、理解 |
| 视空间 | 构图、定位、忽略 |
| 加工速度 | 反应时、符号处理速度 |
两套框架可以互相映射：Gwm ↔ 工作记忆/执行功能，Gs ↔ 加工速度，Glr ↔ 记忆。
### 1.3 关键提醒
一个工作记忆极强、加工速度偏慢的人，和一个反过来的人，在「总分」上可能完全相同，但实际能力结构截然不同。
**因此：雷达图优于总分，分维度百分位优于单一等级。**

## 2. 怎么测：工具与范式
### 2.1 按构念对应工具
| 测量目标 | 经典工具 / 范式 | 施测条件 | 备注 |
| --- | --- | --- | --- |
| 整体智力 | 韦氏量表 WAIS / WISC | 专业人员一对一，60–90 分钟 | 临床与科研金标准 |
| 流体推理 | 瑞文推理测验（Raven） | 纸笔或机测，20–40 分钟 | 文化公平性较好 |
| 工作记忆 | 数字广度、N-back、OSPAN | 机测，5–10 分钟 | N-back 最易游戏化 |
| 抑制控制 | Stroop、Flanker、Go/No-Go | 机测，3–8 分钟 | 关注反应时差异 |
| 认知灵活性 | 连线测验 TMT-B、WCST | 纸笔或机测，5–15 分钟 | 规则切换成本 |
| 加工速度 | 符号数字转换 SDMT、简单反应时 | 机测，2–5 分钟 | 对年龄极敏感 |
| 持续注意 | 持续操作测验 CPT | 机测，10–15 分钟 | 测注意力稳定性 |
| 情景记忆 | 词语学习测验 HVLT-R、逻辑记忆 | 主试施测，10–20 分钟 | 含延迟回忆 |
| 认知筛查 | MoCA、MMSE | 专业人员，10–15 分钟 | 仅用于临床初筛 |
### 2.2 为什么筛查量表不能当测评用
MoCA 和 MMSE 是 **30 分制的临床筛查工具**，设计目标是「找出异常」，不是「区分正常人的高低」。
用它们给健康人群打分会出现严重的**天花板效应**：大多数人集中在 27–30 分，无法区分能力差异，测量精度极低。
> **边界原则**：MindMeter 定位在「自我认知与能力提升」，不进入「筛查—诊断」场景，因此不使用 MoCA / MMSE 这类临床工具。
### 2.3 可游戏化的范式优先级
| 优先级 | 构念 | 范式 | 游戏化难度 |
| --- | --- | --- | --- |
| P0 | 工作记忆 | N-back | 低 |
| P0 | 抑制控制 | Flanker / Go-NoGo | 低 |
| P0 | 加工速度 | 简单选择反应时 | 低 |
| P0 | 情景记忆 | 词表回忆 | 中（需保证编码时间一致） |
| P1 | 认知灵活性 | 任务切换范式 | 中 |
| P2 | 流体推理 | 矩阵推理（瑞文式） | 高（题目生成难） |

## 3. 怎么判断测得准
这是最容易被忽略、也最决定产品生死的一层。
### 3.1 四个核心指标
| 指标 | 含义 | 可接受标准 |
| --- | --- | --- |
| **重测信度** | 隔一段时间重复测量，结果是否稳定 | ICC ≥ 0.75 |
| **内部一致性** | 同一维度的多个试次是否测同一件事 | Cronbach α ≥ 0.7 |
| **效标效度** | 与成熟量表的相关系数 | 需有实证数据支撑 |
| **常模质量** | 参照群体的样本量与抽样方式 | 分层清晰、样本量足够 |
### 3.2 常模为什么是命门
原始分数没有意义，必须转换为**相对位置**：
```
标准分（z） = (个体得分 - 同龄群体均值) / 同龄群体标准差
智商（IQ）  = 100 + 15 × z         （均值 100，标准差 15）
T 分数      = 50  + 10 × z         （均值 50，标准差 10）
百分位      = Φ(z) × 100%
```
所以「IQ 120」的含义是「超过约 91% 的同龄人」，而不是「脑子值 120 分」。
没有常模，78 分和 82 分之间的差距只是噪声。
### 3.3 测量误差有多大
智商测量的 95% 置信区间通常在 **±5 分左右**。
> IQ 108 和 112 在统计上**没有区别**。
单次测量必须带误差范围，否则就是过度解读。报告里写「本次结果误差范围 ±6 分，建议间隔一周复测」，比给一个精确到小数点的分数专业得多。
### 3.4 练习效应
同一套题做第二遍，分数必然上升，升的是**熟悉度**而不是能力。
对策：
- 从大题库**随机抽取**试次
- 准备 **A/B 平行版本**，复测使用另一套
- 报告中区分「练习效应」与「真实变化」

## 4. 四个常见误区
### 4.1 拿自评当测量
「你觉得自己的记忆力怎么样？」——主观报告与客观成绩的相关性通常只有 0.2–0.3。焦虑人群会系统性低估自己，这不是能力问题。
### 4.2 单次测量下定论
睡眠、咖啡因、情绪、动机水平都会显著影响成绩。状态波动足以吃掉 5–10 个百分位。
### 4.3 忽略反应稳定性
两个平均分都是 80 的人：一个稳定在 78–82，一个在 60 和 100 之间剧烈波动——后者可能是注意力问题，也可能是测试本身不可靠。
**反应的变异性本身就是信息**，应当记录并呈现。
### 4.4 用总分掩盖结构
总分相同的两个人，短板完全不同，需要的建议也完全不同。这是 MindMeter 差异化建议的前提。

## 5. 落到 MindMeter
### 5.1 设计链路
```
构念（测什么）
   ↓ 每个构念选一个已验证的范式
范式（怎么测）
   ↓ 包装成游戏，但测量逻辑不变
游戏化（体验）
   ↓ 对照成熟量表做相关分析
效度验证（准不准）
   ↓ 分年龄建立常模
常模（和谁比）
   ↓ 多次测量出趋势 + 置信区间
报告（怎么讲）
```
### 5.2 四个测评游戏的构念映射
| 游戏 | 测量的构念 | 核心指标 | 禁止推断 |
| --- | --- | --- | --- |
| 图案序列记忆 | 工作记忆（Gwm） | 最高正确阶数、正确率 | 不可推断「整体智力」 |
| 颜色干扰点击 | 抑制控制 | 一致/不一致条件下的反应时差 | 不可推断「性格」 |
| 闪现目标点击 | 加工速度（Gs） | 中位反应时、反应时标准差 | 不可推断「注意力缺陷」 |
| 货架物品找回 | 情景记忆（Glr） | 延迟回忆正确率 | 不可推断「记忆力衰退」 |
### 5.3 计分模型（初版建议）
```text
输入：每个试次的 (是否正确, 反应时)
  ↓
剔除异常试次（反应时 < 200ms 或 > 3×该被试中位数）
  ↓
维度得分 = f(正确率, 中位反应时)      // 初版可用加权 z 分数
  ↓
对照同龄常模 → 百分位 + 误差范围
  ↓
输出：雷达图 + 分维度百分位 + 可信度提示
```
规则引擎先行，不要一开始就上机器学习——样本量不足时模型只会放大噪声。
### 5.4 报告设计的四条原则
1. **不做总分**，给雷达图 + 分维度百分位
2. **必须标误差**，每个维度附置信区间
3. **给相对位置**，用「超过 X% 的同龄人」而不是裸分数
4. **给下一步**，每个短板配一条可当天执行的建议
### 5.5 合规边界
| 可以做 | 不可以做 |
| --- | --- |
| 描述认知表现 | 宣称诊断、治疗、预防疾病 |
| 与同龄人比较 | 宣称可替代临床评估 |
| 提供训练建议 | 给出用药或医疗建议 |
| 展示纵向变化 | 承诺「提升智商」 |
> Lumosity 曾因夸大「提升智力、预防痴呆」的宣传，被美国 FTC 处罚 200 万美元。这是同类产品最直接的教训。

## 6. 术语表
| 术语 | 含义 |
| --- | --- |
| 构念（construct） | 想要测量的心理特质，不能直接观察，只能通过行为推断 |
| 常模（norm） | 用于比较的参照群体数据 |
| 信度（reliability） | 测量结果的稳定性与一致性 |
| 效度（validity） | 测量是否真的测到了它声称要测的东西 |
| ICC | 组内相关系数，衡量重测信度的常用指标 |
| 天花板效应 | 题目太简单，大多数人接近满分，无法区分差异 |
| 地板效应 | 题目太难，大多数人接近零分 |
| 练习效应 | 重复施测导致的分数虚高 |
| 平行版本 | 难度相当但内容不同的两套题，用于复测 |
