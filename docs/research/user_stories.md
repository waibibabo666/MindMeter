## 五、故事详情

### US-01 注册/登录后开始（P0 · M1）

**角色**：第一次打开 MindMeter 的用户
**功能**：我想用邮箱注册/登录，跨设备保存我的测评
**价值**：不用每次重测，换设备也能看到历史

```gherkin
场景: 注册
  Given 用户没有账号
  When 用户输入有效邮箱、≥10 位密码并勾选 18+
  Then 应创建账号并返回 access/refresh token
  And 密码应以 argon2/bcrypt 哈希存储
  And 页面不应要求姓名、手机号、年龄、学历

场景: 登录失败限流
  Given 同一邮箱连续失败 5 次
  When 用户再次尝试
  Then 应返回限流提示，而不是无限重试

场景: 刷新令牌
  Given access token 已过期且 refresh 有效
  When 前端调用受保护接口
  Then 应自动 refresh 并重试一次
  And refresh 失效时应回登录页
```

### US-02 18+ 与数据同意（P0 · M1）

**角色**：关心隐私的用户
**功能**：我想在开始前知道数据存什么、存多久、发给谁
**价值**：从而放心注册和测评

```gherkin
场景: 四项同意
  Given 用户进入同意页
  Then 应看到 18+、非诊断、服务端存储、AI 使用四项说明
  And 必须主动勾选后才能开始
  And 未满 18 岁应阻止继续

场景: 数据说明
  Given 用户打开隐私说明
  Then 应看到：存什么、为什么、保留多久、模型厂商、如何删除/导出
  And 不应出现“诊断/治疗/提升智商/常模”等表述
```

### US-03 标准 4 项测评，服务端计分（P0 · M1）

**角色**：愿意花 13 分钟看四项结构的用户
**功能**：我想完成标准 4 项，由服务端算出分数
**价值**：分数可信、可复现，不依赖浏览器

```gherkin
场景: 标准档流程
  Given 用户已登录并同意
  When 用户选择标准档
  Then 任务顺序应为“言语理解 → 知觉速度 → 空间视觉化 → 联想记忆”
  And 每个任务前有 1–2 次练习，练习不计分
  And 完成后前端只提交原始指标

场景: 服务端计分
  Given 前端提交完整原始指标
  When 服务端收到提交
  Then 应按 scoring-v3 计算 4 个维度分
  And 写入 assessment_scores
  And 重复提交同一 assessment 应返回同一结果

场景: 断点恢复
  Given 用户完成 2 个任务后刷新
  Then 已完成任务应保留
  And 当前任务应从说明页重开
```

### US-04 八维报告，没有总分（P0 · M1）

**角色**：刚完成测评的用户
**功能**：我想看到八维雷达图和每个维度分
**价值**：知道自己的结构，而不是一个总分

```gherkin
场景: 报告生成
  Given 用户完成标准 4 项
  When 报告加载
  Then 应显示八维雷达图和 4 个维度分 + 4 个“未测”
  And 不应显示总分/均分/百分位/误差范围
  And 应显示“产品演示参考分，非常模、非临床、无人群比较”

场景: 未测维度
  Given 深度档未测的维度
  Then 该维度应显示“未测”，雷达图留空
  And 不得按 0 分计算
```

### US-05 Agent 解释报告（P0 · M1）

**角色**：看完报告但不确定含义的用户
**功能**：我想让 Agent 用对话解释我的最低维度和下一步
**价值**：从“看到分数”变成“知道做什么”

```gherkin
场景: 首次解读
  Given 用户有当前测评 facts
  When 用户点击“和 Agent 聊聊”
  Then Agent 应引用最低 1–2 个维度给 2–3 条建议
  And 每条建议应来自固定建议库
  And 不应出现诊断/治疗/疗效/提升智商
  And 应显示“AI 生成·非诊断·可关闭”

场景: 没有 facts
  Given 用户没有已完成测评
  When 用户打开对话
  Then Agent 应引导先完成测评，而不是编造分数
```

### US-06 追问并看到依据（P0 · M1）

**角色**：想知道“为什么这项低”的用户
**功能**：我想追问，并看到回答依据
**价值**：能判断 Agent 是不是在编

```gherkin
场景: 解释类追问
  Given 用户问“为什么我联想记忆低”
  When Agent 回答
  Then 回答应引用当前分数和至少 1 个知识块
  And 应显示 source（知识块标题/ID）
  And 数字必须来自 facts

场景: 知识库没有覆盖
  Given 用户问一个知识库没有的问题
  When Agent 回答
  Then 应说“知识库暂未覆盖”，而不是编造
  And 可给出下一步（问什么/看哪份报告）
```

### US-07 接受/拒绝建议（P1 · M1）

**角色**：想按建议行动的用户
**功能**：我想接受或拒绝一条建议，让下次推荐更贴合
**价值**：Agent 不会反复推我已经拒绝的建议

```gherkin
场景: 接受建议
  Given 报告页有 2–3 条建议
  When 用户点击“接受”
  Then 应写入 advice_log（advice_id、accepted=true）
  And 下次推荐应避开已接受的重复项

场景: 拒绝建议
  Given 用户点击“不需要”
  Then 应写入 advice_log（accepted=false）
  And 下次推荐应优先换一条
```

### US-08 编辑自己的记忆画像（P1 · M1）

**角色**：关心“Agent 记住了什么”的用户
**功能**：我想查看/编辑/删除 Agent 对我的画像
**价值**：记忆可控，不是黑盒

```gherkin
场景: 查看/编辑
  Given 用户进入记忆页
  Then 应看到目标、偏好、约束
  When 用户修改“最近在备考”为“已考完”
  Then 后续回答不应再引用旧目标

场景: 删除
  Given 用户删除画像
  Then 后续回答不得引用该画像
  And 页面应显示“暂无画像”
```

### US-09 查看测评摘要与最近对话（P0 · M1）

**角色**：隔了几天回来的用户
**功能**：我想看到上次 Agent 说了什么、这次该接着做什么
**价值**：不用重新讲一遍背景

```gherkin
场景: 摘要
  Given 用户完成一次测评并和 Agent 对话
  When 会话结束
  Then 应写入一条摘要（维度、最低项、建议 ID、变化）
  And 摘要不应包含完整对话原文

场景: 最近 20 条
  Given 用户对话超过 20 条
  Then 只保留最近 20 条消息
  And 更早的消息只通过摘要体现
```

### US-10 复测后看共同维度趋势（P0 · M1）

**角色**：7 天后回来的复测用户
**功能**：我想看到两次都测过的维度的变化
**价值**：知道自己的状态有没有变化，而不是记住一个模糊的数

```gherkin
场景: 共同维度
  Given 用户有两次标准档测评
  When 打开趋势页
  Then 应只显示两次都测过的维度差值
  And 不应显示总分
  And 应提示“变化不等于训练效果”

场景: 间隔太短
  Given 两次测评间隔 <7 天
  Then 应提示练习效应可能影响结果
  And 不得阻止用户查看
```

### US-11 AI 失败时报告仍完整（P0 · M1）

**角色**：网络/模型不稳定的用户
**功能**：我想在 AI 失败时仍能看到报告和趋势
**价值**：不会因为模型挂了就什么都看不到

```gherkin
场景: 模型超时
  Given 用户已开启 AI，但模型 45 秒未返回
  When 报告/对话加载
  Then 应在 2 秒内回退模板
  And 分数/雷达图/趋势不受影响
  And 页面不显示报错栈

场景: Key 失效
  Given 用户 BYOK Key 无效
  Then 应提示“模型不可用，已回退模板”
  And 不要求用户重测
```

### US-12 越界/危机时被安全接住（P0 · M1）

**角色**：问了医疗/危机问题的用户
**功能**：我想被明确告知边界，并得到固定资源
**价值**：产品不越界，也不把用户晾着

```gherkin
场景: 越界问题
  Given 用户问“我是不是有 ADHD/要不要吃药”
  When Agent 回答
  Then 应拒答 + 说明非诊断定位 + 给替代路径
  And 不得给出病名判断/用药建议

场景: 危机关键词
  Given 用户表达自伤/绝望
  Then 不调用模型，直接展示固定资源块
  And 不把该内容用于营销/风控
```

### US-13 导出我的数据（P0 · M1）

**角色**：想带走数据的用户
**功能**：我想导出账号、测评、记忆摘要、建议记录
**价值**：数据可携带，不被锁死

```gherkin
场景: 导出
  Given 用户已登录
  When 用户点击“导出”
  Then 应下载 JSON
  And 包含账号、测评、八维分数、记忆摘要、建议记录
  And 不包含密码、BYOK Key、refresh token
```

### US-14 注销账号并删除数据（P0 · M1）

**角色**：不想继续使用的用户
**功能**：我想注销并让数据在 30 天内清除
**价值**：真正退出，而不是只删登录

```gherkin
场景: 注销
  Given 用户已登录
  When 用户点击“注销账号”并二次确认
  Then 账号应立即停用
  And 30 天内删除或匿名化测评/记忆/对话
  And 页面/邮件告知处理结果

场景: 删除后
  Given 注销完成
  Then 旧 token 不得再访问数据
  And 导出接口不得返回已删除数据
```

### US-15 快测/深度与 8 项、ASR（P1 · M2）

**角色**：想按时间选择深度的用户
**功能**：我想选快测 2 项、标准 4 项或深度 8 项
**价值**：按投入获得不同完整度

```gherkin
场景: 快测
  Given 用户选择快测
  Then 任务为“知觉速度 → 言语流畅性”
  And 言语流畅性使用 ASR，不支持时快测禁用

场景: 深度
  Given 用户选择深度
  Then 任务为 8 项固定顺序
  And 报告显示八维分数，未测显示“未测”
  And 不显示总分
```

### US-16 4 款补充练习（P2 · M2）

**角色**：想随便玩玩的用户
**功能**：我想玩心算/舒尔特/翻牌/快速分类
**价值**：低门槛练习，不影响测评

```gherkin
场景: 练习不计分
  Given 用户打开补充练习
  When 完成一局
  Then 成绩只存 practice，不进报告/雷达图
  And 不影响测评分数
```
