## 二、目的与范围

本文定义 MindMeter 六周 MVP 的功能边界和验收标准。首版只做一件事：让用户在 15 分钟内完成 4 个认知小游戏，看到自己的四维画像和建议。

**本期做**：4 个游戏、计分、报告、建议、本地历史、复测对比、数据清除。

**本期不做**：账号登录、支付、运营后台、AI 解读、自适应测评、临床常模、社区、原生 App。6 周时间只够把核心体验做扎实。

## 三、用户与前提

| 角色 | 说明 |
| --- | --- |
| 体验者 | 18–30 岁大学生/职场新人，无需注册，打开网页即可测评 |
| 项目组 | 维护游戏配置、计分规则和文案，不面向用户提供后台 |

前提：

- 用户使用 Chrome、Edge、Safari 等现代浏览器；
- 测评数据保存在用户本地浏览器，不收集姓名、手机号等身份信息；
- 用户需确认已满 18 岁并理解“本产品不是临床诊断”；
- 首版仅简体中文。

## 四、核心流程

1. 打开首页，了解产品是什么、需要多久、能测什么；
2. 阅读并勾选知情同意与隐私提示；
3. 查看测评说明，完成每个游戏的练习；
4. 依次完成 4 个游戏：工作记忆 → 抑制控制 → 加工速度 → 情景记忆；
5. 前端计分，生成四维画像；
6. 查看报告：分数、雷达图、解释、建议、局限；
7. 结果保存在本地，可复测、查看历史或清除数据。

## 五、功能需求

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-01 | 首页与产品说明 | P0 | 说明产品用途、4 个维度、预计 15 分钟、非临床诊断；有明确的“开始测评”按钮 |
| F-02 | 知情同意与隐私提示 | P0 | 说明数据仅存本地、可随时清除、非诊断用途；必须主动勾选后才能开始；未满 18 岁提示退出 |
| F-03 | 测评说明与练习 | P0 | 每个游戏开始前有 1 屏图文说明 + 按游戏规则完成 1–2 次练习；练习不计分；用户可返回重看说明 |
| F-04 | 测评流程控制 | P0 | 4 个游戏按固定顺序进行；显示进度（第几个/共 4 个）；中途退出需二次确认；同一时间只允许一个测评会话 |
| F-05 | 工作记忆游戏 | P0 | 按规则呈现序列并让用户回忆；记录最长正确长度和正确率；单局 3 分钟左右 |
| F-06 | 抑制控制游戏 | P0 | Go/No-Go 任务；记录正确率、误报次数和反应时；单局 3 分钟左右 |
| F-07 | 加工速度游戏 | P0 | 简单反应时任务；记录中位反应时和漏答次数；单局 2 分钟左右 |
| F-08 | 情景记忆游戏 | P0 | 先学习 12 个词语/图片，再做 24 项旧新再认；记录再认正确率；单局 4 分钟左右 |
| F-09 | 自动计分 | P0 | 4 个游戏完成后自动计算原始指标和 0–100 参考分；同一输入同一版本结果一致；计算在 2 秒内完成 |
| F-10 | 认知画像报告 | P0 | 展示四维雷达图、每个维度的分数与一句话解释、总体摘要、局限说明；不使用“诊断/正常/异常”等临床表述 |
| F-11 | 行动建议 | P0 | 根据最低的 1–2 个维度给出 2–3 条具体、可执行的建议；不承诺疗效，不提供治疗建议 |
| F-12 | 历史与复测 | P1 | 本地保存每次测评的时间、四维分数；至少 2 次测评后可查看变化；提示复测间隔建议 7 天，但不强制 |
| F-13 | 数据清除 | P0 | 设置页提供“清除全部数据”；二次确认后删除本地所有测评记录；清除后不可恢复 |
| F-14 | 异常恢复 | P1 | 刷新或误关页面后，重新进入可恢复当前游戏进度；无法恢复时明确提示并从当前游戏重开，不静默丢失整份结果 |
| F-15 | 分享卡片 | P2 | 生成不含分数的四维画像卡片，默认隐藏具体数值；可保存为图片；时间不够可延期 |

## 六、四个游戏的规则

| 游戏 | 玩法 | 试次 | 主要指标 | 目标时长 |
| --- | --- | --- | --- | --- |
| 工作记忆 | 屏幕依次闪现方块/数字序列，用户按顺序复现；长度从 3 逐步增加到 7 | 2 次练习 + 8 次正式 | 最长正确长度、正确率 | 3 分钟 |
| 抑制控制 | 看到绿色圆点尽快点击，看到红色圆点不点（Go/No-Go） | 2 次练习 + 40 次正式（约 25% No-Go） | 正确率、误报次数、平均反应时 | 3 分钟 |
| 加工速度 | 屏幕出现目标后尽快点击；目标出现前有 1–3 秒随机等待 | 2 次练习 + 20 次正式 | 中位反应时、漏答次数 | 2 分钟 |
| 情景记忆 | 先看 12 个词语/图片 20 秒，再从 24 项中判断“见过/没见过” | 1 次练习 + 24 次正式 | 再认正确率、误报率 | 4 分钟 |

规则细节：

- 所有游戏开始前必须有练习，练习结果不计入分数；
- 反应时类游戏允许鼠标、触屏和键盘操作；
- 每个游戏结束后展示一句中性反馈，不显示“你很差/你很聪明”等评价；
- 游戏参数（试次、时长、阈值）集中放在配置文件中，便于调整。

## 七、计分与报告

### 7.1 计分

1. 每个游戏输出 1–2 个原始指标（如最长长度、正确率、中位反应时）。
2. 将原始指标按团队设定的最小/最大值线性映射到 0–100 的**参考分**；超出范围截断到 0 或 100。
3. 四个参考分组成四维画像；不计算“总智商”或“脑力排名”。
4. 映射阈值写在 `scoring-config` 中并标注版本；报告页明确写“课程演示参考分，非常模、非临床”。

### 7.2 报告结构

1. 一句话摘要：本次测评的整体状态；
2. 四维雷达图；
3. 四个维度卡片：分数、原始指标、一句话解释；
4. 2–3 条行动建议（对应最低维度）；
5. 局限说明：样本少、无临床常模、受状态影响；
6. 复测入口与历史记录；
7. 免责声明与数据清除入口。

### 7.3 建议规则

- 取分数最低的 1–2 个维度，各给 1–2 条建议；
- 建议必须是具体动作，例如“每天 10 分钟双 n-back 练习”“减少多任务切换”；
- 不使用“治疗”“改善注意力缺陷”“提升智商”等表述；
- 建议文案集中配置，便于产品负责人统一修改。

## 八、数据与存储

首版不建账号、不接数据库，使用浏览器 `localStorage` 保存测评记录。

```json
{
  "version": 1,
  "sessions": [
    {
      "id": "uuid",
      "startedAt": "2026-10-19T20:00:00+08:00",
      "finishedAt": "2026-10-19T20:14:30+08:00",
      "results": {
        "workingMemory": { "maxSpan": 5, "accuracy": 0.75 },
        "inhibition": { "accuracy": 0.88, "commissionErrors": 3, "meanRt": 420 },
        "speed": { "medianRt": 310, "omissions": 1 },
        "memory": { "accuracy": 0.79, "falseAlarmRate": 0.12 }
      },
      "scores": {
        "workingMemory": 62,
        "inhibition": 78,
        "speed": 71,
        "memory": 66
      },
      "reportVersion": "1.0"
    }
  ]
}
```

要求：

- 不存储姓名、手机号、身份证号、精确地址等身份信息；
- 只存测评所需的数据和本地生成的时间戳；
- 存储写入失败（如隐私模式、空间不足）时提示用户，不假装保存成功；
- 用户可一键清除全部数据；
- 如后续增加导出，导出文件同样不含身份信息。

## 九、业务规则

| ID | 规则 |
| --- | --- |
| BR-01 | 所有结果仅用于自我了解和课程演示，不构成临床诊断、治疗建议或风险判定 |
| BR-02 | 仅面向 18 岁及以上用户；未满 18 岁提示退出 |
| BR-03 | 参考分使用团队设定的演示阈值，必须标注“非常模、非临床” |
| BR-04 | 不伪造中文常模、信效度数据或临床验证结论 |
| BR-05 | 建议复测间隔 ≥7 天，但不强制阻止用户复测；报告提示练习效应 |
| BR-06 | 同一时间只允许一个测评会话，避免多标签页互相覆盖 |
| BR-07 | 默认不收集身份信息，不接入广告或第三方追踪 |
| BR-08 | 数据默认仅保存在用户本地，清除后不可恢复 |

## 十、验收标准

- 4 个游戏均可独立完成，全流程 ≤15 分钟；
- 报告在计分完成后 2 秒内展示；
- 刷新页面后可恢复当前游戏，不丢失已完成游戏的结果；
- 360px 宽手机屏幕可正常操作，无横向滚动；
- 10–15 名用户试用，首次完成率 ≥80%，至少 4/5 能说出报告核心结论；
- Chrome、Edge、Safari 最近两个版本无阻断性问题；
- 无控制台报错，无静默数据丢失；
- 代码仓库包含启动说明，项目组其他成员可按说明运行。

## 十一、非目标

- 不做账号、登录、支付、订阅；
- 不做运营后台、题库管理界面；
- 不做 AI 解读、自适应测评（CAT）；
- 不做临床常模、诊断报告、认知障碍筛查；
- 不做社区、排行榜、好友 PK；
- 不做原生 iOS/Android App；
- 不做多语言。
