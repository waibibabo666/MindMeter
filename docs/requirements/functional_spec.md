## 二、目的与范围

本文定义 MindMeter L2 的功能边界和验收标准：用户注册登录后完成 8 项能力测评（快测/标准/深度），服务端生成八维参考分；Agent 结合测评 facts、长期记忆和知识库，进行报告解读、行动建议、追问回答和复测趋势解释。

**本期做**：

- 用户名 + 密码账号、服务端会话（HttpOnly Cookie）登录/登出/注销；
- 8 项测评：快测 2 / 标准 4 / 深度 8；服务端计分；
- 八维报告：0–100 参考分、雷达图、2–3 条建议；不设总分、无常模、无百分位；
- Agent 对话：报告解读、建议、追问、趋势解释；
- 记忆：最近 20 条消息、用户画像、每次测评摘要、建议接受记录；
- RAG：服务端知识库（PostgreSQL，30 条已审知识块）+ pgvector/关键词检索、回答引用；
- 长期监测：共同维度趋势、7 天复测提示；
- 数据导出/删除、账号注销；
- 4 款补充练习（P2，不阻塞主链路）。

**本期不做**：

- 常模、百分位、误差范围、总分、智商/脑龄；
- 临床诊断、治疗、药物建议、危机干预替代；
- 7 天计划/打卡、情绪支持/心理疏导；
- B 端、付费订阅、原生 App、多语言；
- 全自动多 Agent 自治；
- 保存全部对话原文（只留最近 20 条 + 摘要）。

## 三、用户与前提

| 角色 | 说明 |
| --- | --- |
| 用户 | 18 岁以上，用户名注册（不收集邮箱与身份信息），可跨设备登录后查看测评与记忆 |
| 游客 | 不做：未登录只能看登录/注册页（数据按账号隔离是产品前提） |
| 管理员 | 仅内部知识库/内容维护，不查看用户对话；当前用脚本与数据库操作，不做后台 |

前提：

- 现代浏览器（Chrome/Edge/Safari 最近两版）；言语流畅性 ASR 仅 Chrome/Edge；
- 服务端部署 HTTPS；**模型由站点统一提供**（`MM_LLM_*` 环境变量），Key 不进数据库、不进浏览器；未配置时全部走模板兜底；
- 用户已满 18 岁并同意隐私/数据使用说明；
- 首版仅简体中文。

## 四、核心流程

1. 注册/登录（用户名 + 密码）；
2. 选择快测/标准/深度；
3. **「第一次见面」页（每账号一次）**：年龄 + 最高学历 + 知情同意（18+、非诊断、数据按账号存储）——存进账号，换设备不再重问；
3b. **「今天的状态」页（每次测评）**：昨晚睡眠 + 当前疲劳，只用于有效性标记，不进账号档案；
4. 完成 2/4/8 个任务，每个任务前有 1–2 次练习；
5. 提交原始指标，服务端计分；
6. 查看八维报告；不显示总分；
7. 与 Agent 对话：解释、建议、追问；
8. 每轮有效对话结束后，服务端自动沉淀摘要与建议记录（画像只在用户确认后写入，未确认只回传草稿线索）；用户可查看/编辑/删除；
9. 7 天后复测；Agent 比较共同维度，解释趋势；
10. 用户可导出数据或注销账号。

## 五、功能需求

### 5.1 账号与认证

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-01 | 注册 | P0 | 用户名（2–32 位，字母/数字/点/下划线/中文，归一化小写）+ 密码；密码 ≥8 位且含字母与数字；重复用户名拒绝（409）；18+ 与边界勾选为必选项；**不收集邮箱/姓名/手机号**（年龄与最高学历属于"第一次见面"页采集的分段参考项，存在账号内、不参与计分） |
| F-02 | 登录/登出 | P0 | 用户名 + 密码；失败统一 401 `invalid_credentials`（不区分用户名/密码）；按 `IP+用户名` 限流（默认 10 次/5 分钟 → 429）；未知用户名也执行一次 PBKDF2 以对齐时序；登出撤销服务端会话行 |
| F-03 | 会话保持 | P0 | 不透明随机令牌存 `HttpOnly + SameSite=Lax + Secure(auto)` Cookie；数据库只存 `sha256(token)`；30 天滑动续期；会话失效一律 401，前端广播一次并回登录页；**不把 token 放 URL 或 localStorage** |
| F-04 | 密码修改/重置 | P1 | 已实现改密（需当前密码，改后撤销其他设备会话）；因不收集邮箱，**不提供自助找回**，登录页与设置页明示需联系发起人；邮件重置为 M2 可选项 |
| F-05 | 注销账号 | P0 | 二次确认 + 当前密码；立即硬删除（`ON DELETE CASCADE` 级联清测评/分数/记忆/对话/AI 运行记录）；“30 天内清除”由托管数据库的备份能力代替；用户名可被重新注册 |
| F-06 | 数据导出 | P0 | `GET /export` 返回本账号 JSON：测评、八维分数、记忆摘要、建议、对话、进度；**不含密码、不含 Key**（模型由站点提供，前端从未持有）；`DELETE /data` 只清本账号数据 |

### 5.2 测评

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-07 | 三档选择 | P0 | 快测 2 / 标准 4 / 深度 8；5/13/28 分钟；快测需 ASR，不支持时禁用并提示 |
| F-08 | 知情同意 | P0 | 与年龄/学历合并在「第一次见面」一页：18+ 与非诊断/数据说明两项主动勾选才能继续；同意版本随条款升级重新确认；未满 18 退出；睡眠/疲劳等临场项在下一页，每次都填 |
| F-09 | 任务运行 | P0 | 固定顺序；显示进度；1–2 次练习不计分；正式试次不显示对错；输入延迟 ≤100ms |
| F-10 | 8 项任务 | P0 | 言语理解 15 题/3 分钟；言语流畅性 60 秒 ASR；数字运算 20 题/3 分钟；知觉速度 60 秒；归纳推理 15 题/5 分钟；空间视觉化 20 题/3 分钟；联想记忆 12 对+24 题/3 分钟；自然知识 20 题/3 分钟 |
| F-11 | 断点恢复 | P0 | 每任务完成写服务端 draft；刷新保留已完成任务；当前任务从说明页重开；24 小时过期 |
| F-12 | 提交与计分 | P0 | 前端提交原始指标；服务端按 `scoring-v3` 计算；同输入同版本同输出；提交幂等 |
| F-13 | 报告 | P0 | 八维雷达图、维度分、完成度、2–3 条建议、局限；未测显示“未测”；**不显示总分/均分/百分位/误差范围** |
| F-14 | 报告访问 | P0 | 仅本人可读；分享/公开默认关闭（M3 再评估） |

### 5.3 Agent 对话

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-15 | 报告解读 | P0 | 基于当前 facts 生成 ≤200 字解读；必须引用维度分；不诊断、不比较人群 |
| F-16 | 行动建议 | P0 | 取最低 1–2 个已测维度，给 2–3 条建议；建议来自固定库；不承诺疗效 |
| F-17 | 追问 | P0 | 支持最近 20 条上下文；意图分类：解释/澄清/无关/越界/危机；越界/危机走固定话术 |
| F-18 | 记忆使用 | P0 | 回答可引用用户目标/上次建议/复测差值；不得引用未授权或已删除数据 |
| F-19 | 知识库引用 | P0 | 回答附 `source`（知识块 ID/标题）；检索不到时明确说“不知道”，不编造 |
| F-20 | 校验与降级 | P0 | 禁用词、数字来源、建议 ID、长度、引用五项校验；失败重试一次→模板；报告页不空 |
| F-21 | 趋势解释 | P0 | 趋势并入报告页「与上次相比」区块（`#/trend` 重定向到 `#/report`）：只有一次测评时显示本次分数作为基线并说明下次复测起可比，不摆空态；只比较共同维度；至少 2 次才显示差值，至少 3 次才给“趋势”措辞；<7 天提示练习效应；不判断“进步/退步” |

### 5.4 记忆与长期监测

| ID | 功能 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F-22 | 用户画像 | P1 | 目标/偏好/约束由用户确认后写入；可查看/编辑/删除 |
| F-23 | 测评摘要 | P0 | 每次测评后生成摘要（维度、最低项、建议 ID、变化）；不存原始对话 |
| F-24 | 建议记录 | P1 | 记录展示/接受/拒绝的建议 ID；用于下次推荐避重 |

## 十、验收标准

- 注册→登录→标准 4 项→报告→对话→摘要→7 天后复测→趋势，全链路可走通（刷新与换设备登录后数据仍在）；
- 服务端计分与金标准用例一致；同输入同版本同输出；
- 报告无总分/百分位/误差范围；未测显示“未测”；
- **多租户隔离**：两个账号互不可见（`tests/backend/test_tenancy.py` 全绿，跨账号 id 读取 404）；
- Agent 30 条用例：准确/有依据/有用/无越界各 ≥4/5；禁用词 0；幻觉数字 0；
- RAG hit@3 ≥80%；回答引用率 ≥90%；
- 记忆：20 条上限、摘要可查、删除后不再被引用；
- 账号注销即时删除；导出完整且不含 Key/密码；
- API p95 ≤500ms（非 AI）；AI 完整 ≤30s（M1 非流式），失败 ≤2s 回退模板；
- 移动端 360px 可用；无明显无障碍阻断；
- 无高危漏洞；Key 不出现在日志/导出/前端源码；口令与令牌在库内均为散列。
