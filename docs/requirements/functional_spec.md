## 二、目的与范围

本文定义 MindMeter 本期的功能边界和验收标准：用户在 **快测 / 标准 / 深度** 三档中选择一档，用 **5 / 13 / 28 分钟** 完成 2 / 4 / 8 项能力任务，得到 **八维参考分画像**、2–3 条行动建议和本地复测记录。

**本期做**：

- 8 项能力任务：言语理解、言语流畅性、数字运算、知觉速度、归纳推理、空间视觉化、联想记忆、自然探索；
- 快测 2 项、标准 4 项、深度 8 项；
- 0–100 维度参考分、八维雷达图、维度解释、2–3 条建议；
- 本地历史、复测对比、数据清除、任务边界断点恢复；
- 可选 AI 解读/追问/复测解释：**BYOK（用户自带模型 API Key）**，默认关闭，模板兜底；
- 4 款补充练习游戏（不计分，P2）。

**本期不做**：

- 账号、登录、手机号/邮箱、支付、运营后台；
- 自建后端、云数据库、云端保存测评数据；
- 常模、百分位、“超过 X% 同龄人”、误差范围数字；
- 总分、四项均分、智商换算、脑龄、认知类型标签；
- 临床诊断、治疗建议、药物建议、危机干预；
- 自适应测评（CAT）、AI 判分、AI 决定维度；
- 两周训练计划、理解度复盘、AI 生成后自检、语音多模态；
- 社区、排行榜、原生 App、多语言、B 端/付费版本。

## 三、用户与前提

| 角色 | 说明 |
| --- | --- |
| 体验者 | 18 岁及以上，无需注册，打开网页即可测评 |
| 复测者 | 已做过一次，7 天后回来查看维度变化 |
| 项目组 | 维护任务参数、计分规则、建议库和文案，不面向用户提供后台 |

前提：

- 用户使用 Chrome、Edge、Safari 等现代浏览器；言语流畅性 ASR 仅支持 Chrome/Edge；
- 测评数据只保存在用户本地浏览器，不收集姓名、手机号、身份证号、学校、公司等身份信息；
- 用户需确认已满 18 岁，并理解“本产品不是医疗器械、不提供诊断”；
- 首版仅简体中文；
- AI 为可选项，用户不开启时产品功能完整。

## 四、核心流程

1. 打开首页，了解产品是什么、三档时长、能测什么；
2. 选择快测 / 标准 / 深度；
3. 阅读并勾选“已满 18 岁”“理解非诊断用途、数据只存本地”；
4. 按档位依次完成 2 / 4 / 8 个任务，每个任务开始前有 1–2 次练习；
5. 本地计分，生成八维画像；
6. 查看报告：维度分、雷达图、解释、建议、局限；不显示总分；
7. 结果保存在本地，可复测、查看历史、清除数据；
8. 可选：在设置中填入自己的模型 API（BYOK），开启 AI 解读/追问/复测解释。

## 六、三档与任务规则

### 6.1 三档

| 档位 | 维度 | 任务顺序 | 预计时长 |
| --- | --- | --- | --- |
| 快测 | 2 项：知觉速度、言语流畅性 | 知觉速度 → 言语流畅性 | 5 分钟 |
| 标准 | 4 项：言语理解、知觉速度、空间视觉化、联想记忆 | 言语理解 → 知觉速度 → 空间视觉化 → 联想记忆 | 13 分钟 |
| 深度 | 8 项：标准 4 项 + 数字运算、归纳推理、自然探索、言语流畅性 | 言语理解 → 数字运算 → 归纳推理 → 知觉速度 → 空间视觉化 → 联想记忆 → 自然探索 → 言语流畅性 | 28 分钟 |

### 6.2 任务参数

| 维度 | 任务 | 题量/时长 | 主要指标 |
| --- | --- | --- | --- |
| 言语理解 | 近义词/反义词/句子理解四选一 | 15 题 / 3 分钟 | 正确数 |
| 言语流畅性 | 60 秒动物命名（ASR） | 60 秒 | 不重复有效动物名数 |
| 数字运算 | 两位数加减/简单乘法四选一 | 20 题 / 3 分钟 | 正确数 |
| 知觉速度 | 目标符号—四选项匹配 | 60 秒 | 正确匹配数 |
| 归纳推理 | 数列/字母序列/简单矩阵四选一 | 15 题 / 5 分钟 | 正确数 |
| 空间视觉化 | 心理旋转四选一 | 20 题 / 3 分钟 | 正确数、中位反应时 |
| 联想记忆 | 12 组词对学习 + 24 题配对再认 | 学习 30 秒 + 3 分钟 | 命中数、虚报数 |
| 自然探索 | 自然图片四选一分类 | 20 题 / 3 分钟 | 正确数 |

### 6.3 规则细节

- 每个任务开始前有 1–2 次练习，练习不计分；练习可显示对错，正式试次不显示对错；
- 反应时类任务允许鼠标、触屏和键盘操作；输入延迟目标 ≤100ms；
- 言语流畅性只使用 ASR，不提供键盘替代；浏览器不支持或麦克风被拒时，快测不可用，深度档该维度记“未测”；
- 所有任务参数（题量、时长、阈值）集中在配置中，便于调整；
- 任务结束展示中性反馈，不显示“你很差/你很聪明”等评价。

## 七、计分与报告

### 7.1 计分

1. 每个任务输出原始指标（正确数、有效词数、命中/虚报、中位反应时等）。
2. 按团队设定的演示阈值映射到 0–100 的**参考分**；超出范围截断到 0 或 100。
3. 八个维度各自独立计分；**不计算总分、均分、智商或排名**。
4. 未完成/数据不足的维度返回 `null`，报告显示“未测”，不按 0 分处理。
5. 计分配置版本写入每条记录；报告固定写“课程演示参考分，非常模、非临床、无人群比较”。

### 7.2 报告结构

1. 一句话摘要：本次完成了哪一档、哪些维度；
2. 八维雷达图（未测维度留空）；
3. 八张维度卡片：分数、原始指标、一句中性解释；未测显示“未测”；
4. 2–3 条行动建议（对应最低的 1–2 个已测维度）；
5. 完成度与局限说明：样本少、无临床常模、受状态影响、不同档位只比共同维度；
6. 复测入口、历史记录、数据清除入口；
7. 可选 AI 解读区：标注“AI 生成·非诊断·可关闭”，模板兜底。

### 7.3 建议规则

- 只取最低的 1–2 个已测维度，各 1–2 条，总 2–3 条；
- 建议必须是具体动作，例如“每天 10 分钟空间序列练习”“减少多任务切换”；
- 不使用“治疗”“改善注意力缺陷”“提升智商”等表述；
- 建议文案集中配置，便于产品负责人统一修改。

## 八、数据与存储

首版不建账号、不接数据库、不做后端，使用浏览器 `localStorage`。

```json
{
  "schemaVersion": 1,
  "scoringVersion": "scoring-v3",
  "sessions": [
    {
      "id": "s_20261024_1",
      "tier": "deep",
      "startedAt": "2026-10-24T20:00:00+08:00",
      "finishedAt": "2026-10-24T20:28:00+08:00",
      "scores": {
        "vc": 62, "vf": 55, "nc": 70, "ps": 68,
        "ir": 51, "sv": 74, "am": 60, "ni": 66
      },
      "tasks": {
        "vc": { "status": "done", "correct": 9, "total": 15 },
        "am": { "status": "done", "hits": 9, "falseAlarms": 3 }
      },
      "ai": { "enabled": false, "model": null }
    }
  ]
}
```

要求：

- 不存储姓名、手机号、身份证号、学校、公司、精确地址等身份信息；
- 不存储年龄、学历等人口学字段；只存“已满 18 岁”的布尔确认；
- 只存测评所需数据、本地时间戳、档位和计分版本；
- 存储写入失败（隐私模式/空间不足）时提示用户，不假装保存成功；
- 用户可一键清除全部数据；清除后不可恢复；
- AI 的 API Key 只存本机，不写入导出文件，不上传。

## 十、验收标准

- 快测 5 分钟、标准 13 分钟、深度 28 分钟（含说明和练习，允许 ±20%）；
- 8 个任务均可独立完成；未测维度正确显示“未测”；
- 报告模板在最后一个任务完成后 **≤1 秒** 展示；AI 单次 **≤8 秒**，超时降级；
- 首次完成率：快测 ≥85%、标准 ≥80%、深度 ≥60%；
- 360px 宽手机屏幕可操作，无横向滚动；按钮 ≥44×44px；
- Chrome、Edge、Safari 最近两个版本无阻断性问题；ASR 仅 Chrome/Edge；
- 无控制台报错，无静默数据丢失；
- 刷新后已完成任务保留，当前任务从说明页重开；
- 设置页可清除全部数据；清除后历史为空；
- 关闭 AI 时报告完整，不出现空白或报错；
- 代码仓库包含启动说明，项目组其他成员可按说明运行。

## 十一、非目标
