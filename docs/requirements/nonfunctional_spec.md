## 三、质量目标

<<<<<<< HEAD
### 1.1 目的

本文定义 MindMeter 的可度量质量门槛，回答「做到什么程度才算合格」，并规定验证方法与发布门禁。功能需求回答「做什么」，本文回答「做得多好、如何证明」。

### 1.2 范围

覆盖性能与容量、可靠性、安全、隐私合规、可用性与无障碍、兼容性、可维护性、可观测性、数据与科学质量、本地化、法律伦理。

不覆盖具体技术选型与实现方案（见[软件设计](../software.md)），也不覆盖付费、运营后台、通知推送（功能需求 v0.2 已列为范围外）。

### 1.3 目标值与确认状态

- 文中数值为课程项目可执行目标，用于架构与测试设计；已无未决占位符。
- 任何目标下调必须记录理由与影响，并经项目组评审确认。
- 指标必须在测试环境实测，不能只凭设计声明。

### 1.4 质量模型

参考 ISO/IEC 25010 质量模型，结合心理测评产品的特殊性（科学性、隐私、伦理）扩展「数据与科学质量」「法律与伦理」两类。
