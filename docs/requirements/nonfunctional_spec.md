## 二、目的与范围

本文回答“做到什么程度才算合格”，覆盖性能、兼容性、可用性、隐私、安全、科学质量、可维护性和成本。功能需求回答“做什么”，本文回答“做得多好、怎么验证”。

不覆盖：

- 账号、登录、支付、运营后台；
- 云端存储、跨设备同步、服务端计分；
- 临床常模、信效度验证、医学诊断；
- 99.9% 可用性、RTO/RPO、异地容灾、每日备份；
- 等保、DPIA、ISO 27001、付费渗透测试；
- 全站 WCAG 2.1 AA 认证、7×24 值班。

## 四、详细非功能需求

### 4.1 性能（NFR-PERF）

| ID | 指标 | 目标 | 测法 |
| --- | --- | --- | --- |
| NFR-PERF-01 | 首屏加载 | 4G 下 ≤3 秒 | Lighthouse、真机 |
| NFR-PERF-02 | 首包体积 | ≤300KB（gzip），不含题目图片/音频 | 构建检查 |
| NFR-PERF-03 | 任务输入响应 | 点击/按键到反馈 ≤100ms | `performance.now` + rAF |
| NFR-PERF-04 | 单任务计分 | ≤100ms | 计时 |
| NFR-PERF-05 | 模板报告 | 最后一个任务完成后 ≤1 秒 | 计时 |
| NFR-PERF-06 | AI 单次生成 | ≤8 秒，超时降级 | 计时 + 断网 |
| NFR-PERF-07 | 总时长 | 快测 5 / 标准 13 / 深度 28 分钟，允许 ±20% | 5 人走查 |
| NFR-PERF-08 | 动画帧率 | ≥50fps（中端机） | 真机 |

### 4.2 兼容性（NFR-COMPAT）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-COMPAT-01 | 桌面浏览器 | Chrome/Edge/Safari 最近 2 个主版本 |
| NFR-COMPAT-02 | 移动系统 | iOS 15+、Android 10+ |
| NFR-COMPAT-03 | 分辨率 | 360×640 至 1920×1080，无横向滚动 |
| NFR-COMPAT-04 | 输入方式 | 触屏、鼠标、键盘；按钮 ≥44×44px |
| NFR-COMPAT-05 | ASR | 仅 Chrome/Edge 的 Web Speech API；不支持时明确提示，不静默失败 |
| NFR-COMPAT-06 | 网络 | 静态页面可离线打开；AI/ASR 需要网络 |

### 4.3 可靠性与恢复（NFR-REL）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-REL-01 | 数据不丢 | 每完成一个任务写一次 draft；刷新后保留已完成任务 |
| NFR-REL-02 | 当前任务恢复 | 从该任务说明页重开，不要求重做已完成任务 |
| NFR-REL-03 | draft 过期 | 24 小时；过期后提示重新开始 |
| NFR-REL-04 | 存储失败 | 隐私模式/空间不足时明确提示，不假装保存成功 |
| NFR-REL-05 | 单会话 | 同一时间只允许一个测评会话；多标签页提示接管或退出 |
| NFR-REL-06 | 计分幂等 | 同一输入 + 同一配置版本 = 同一输出 |

### 4.4 隐私与数据（NFR-PRIV）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-PRIV-01 | 最小化 | 不收集姓名、手机号、身份证号、学校、公司、年龄、学历 |
| NFR-PRIV-02 | 本地存储 | 测评数据只存 `localStorage`；不上传、不落云 |
| NFR-PRIV-03 | 同意 | 开始前主动勾选“18+”“非诊断、数据只存本地” |
| NFR-PRIV-04 | 清除 | 一键删除 sessions/draft/settings/practice 四类键 |
| NFR-PRIV-05 | 无追踪 | 不接广告 SDK、第三方统计、社交登录 |
| NFR-PRIV-06 | ASR | 音频不落库；仅在言语流畅性任务中调用浏览器语音服务；页面提示可能使用浏览器厂商服务 |
| NFR-PRIV-07 | AI | 默认关闭；BYOK；只发维度分与 facts，不发身份/人口学/原始试次；Key 只存本机 |
| NFR-PRIV-08 | 导出 | 如后续增加导出，文件不含身份信息和 API Key |

### 4.5 安全（NFR-SEC）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-SEC-01 | 传输 | 线上 HTTPS |
| NFR-SEC-02 | 密钥 | 仓库零密钥；BYOK Key 仅用户本机；页面提示风险 |
| NFR-SEC-03 | 输入 | 所有用户输入/模型输出做转义；不使用 `eval` |
| NFR-SEC-04 | 依赖 | 零第三方依赖或锁定版本；构建时扫描高危漏洞 |
| NFR-SEC-05 | 模型输出 | 禁用词拦截、长度限制、数字必须来自 facts；失败回退模板 |
| NFR-SEC-06 | 清数据 | 清除数据时同时清除 BYOK Key 和 draft |

### 4.6 可用性与无障碍（NFR-USA）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-USA-01 | 键盘 | 主流程可键盘完成，焦点可见 |
| NFR-USA-02 | 对比度 | 正文 ≥4.5:1，大字 ≥3:1 |
| NFR-USA-03 | 非颜色唯一 | 对错/状态同时用文字或形状表达 |
| NFR-USA-04 | 减少动效 | 尊重 `prefers-reduced-motion` |
| NFR-USA-05 | 文案 | 避免临床化措辞；关键结论可理解率 ≥80% |
| NFR-USA-06 | 错误提示 | 说明“发生了什么、下一步怎么办” |

> 本期不承诺全站 WCAG 2.1 AA 认证；关键路径做基本键盘/对比度/非颜色检查。

### 4.7 科学质量（NFR-SCI）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-SCI-01 | 可复现 | 同输入 + 同配置版本 = 同输出 |
| NFR-SCI-02 | 无总分 | 报告不出现总分、均分、智商、脑龄、排名 |
| NFR-SCI-03 | 无常模 | 不出现百分位、“超过 X% 同龄人”、误差范围数字 |
| NFR-SCI-04 | 表述诚实 | 固定写“课程演示参考分、非常模、非临床、无人群比较” |
| NFR-SCI-05 | 未测处理 | 数据不足显示“未测”，不按 0 分，不静默插补 |
| NFR-SCI-06 | 跨档可比 | 只比较共同维度；不同档位不比较“总分” |
| NFR-SCI-07 | 局限 | 报告写明样本少、无临床常模、受状态影响、练习效应 |
| NFR-SCI-08 | 版本 | 计分版本写入每条记录；旧版本不可原地修改 |

### 4.8 可维护性（NFR-MAINT）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-MAINT-01 | 计分独立 | `core_engine` 纯函数，不操作 DOM、不发请求 |
| NFR-MAINT-02 | 参数集中 | 题量、时长、阈值集中在一个配置对象 |
| NFR-MAINT-03 | 测试 | 每个任务至少正常/边界/缺失三类单测 |
| NFR-MAINT-04 | 文档 | README 写清启动方式；数据 schema 与键名有说明 |
| NFR-MAINT-05 | 依赖 | 原生 HTML/CSS/JS，不引入构建链；如引入需说明理由 |

### 4.9 成本与部署（NFR-COST）

| ID | 要求 | 目标 |
| --- | --- | --- |
| NFR-COST-01 | 托管 | GitHub Pages / Vercel / Netlify 免费额度 |
| NFR-COST-02 | 后端 | 零后端；无服务器、无数据库 |
| NFR-COST-03 | AI | BYOK，由用户承担模型费用；项目组不代付 |
| NFR-COST-04 | 月成本 | ≤¥100（仅域名/可选托管） |

## 五、约束

| 类别 | 约束 | 影响 |
| --- | --- | --- |
| 时间 | 6 周，W1–W6，每周五可演示 | 8 项任务必须分档交付 |
| 人力 | 4 人兼职 | 不做后端、不做常模、不做多语言 |
| 技术 | 原生 Web；静态托管 | 无服务端；AI/ASR 依赖浏览器能力 |

| 合规 | 非医疗器械、18+、不收集身份信息 | 文案与同意页必须一致 |

## 六、验收方法

| 领域 | 方法 | 通过标准 |
| --- | --- | --- |
| 性能 | Lighthouse + 手动计时 | NFR-PERF-01/03/05/06 达标 |
| 兼容 | Chrome/Edge/Safari + iOS/Android 各一台 | 核心流程无阻断 |
| 可靠 | 刷新、断网、关标签页 | 已完成任务不丢，当前任务可恢复 |
| 易用 | 10–15 人测试 | 完成率 85/80/60；4/5 能说出最低维度 |
| 隐私 | 代码检查 + 演示 | 无身份字段、无追踪、可清除 |
| 安全 | `npm audit` + 手动检查 | 无高危；无硬编码 Key |
| 科学 | 单测 + 文案评审 | 同输入同输出；无总分/常模/百分位 |
| 部署 | 线上访问 + 手机热点 | 可公开访问；断网可打开静态页 |

## 七、发布底线

满足以下条件才能在第 6 周演示：

- 三档都能完整跑通，总时长在 5/13/28 分钟目标内；
- 八维报告能生成，未测维度正确显示“未测”，无总分；
- 360px 手机可操作，刷新不丢已完成任务；
- 隐私提示、数据清除、18+ 门槛、非诊断声明都在；
- AI 关闭时报告完整；开启后 8 秒超时能回退模板；
- 线上链接可访问，另备本地版本和演示视频；
- 无阻塞演示的控制台报错。

## 八、明确不做

以下要求对 4 人 / 6 周课程项目没有必要，本期不纳入验收：

- 99.9% 可用性、RTO/RPO、异地容灾、每日备份；
- 等保备案、DPIA、ISO 27001、付费渗透测试；
- 多语言、多时区、多币种；
- 全站 WCAG 2.1 AA 认证；
- 全链路监控、告警值班、日志平台；
- 50/200 并发、压测、自动扩缩容；
- 应用商店上架、原生 App 适配；
- 账号、支付、运营后台、客服工单；
- 常模、百分位、信效度验证、临床诊断。
