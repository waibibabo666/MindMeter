## 二、一句话

**计分是确定的，AI 只负责把已经算好的八维结果讲成人话。** 它不算分、不改结论、不编数字、不新增建议；模型不可用时模板照常出报告。

## 三、AI 只做三件事

| 场景 | 输入 | 输出 | 优先级 | 上线 |
| --- | --- | --- | --- | --- |
| 报告解读 | 八维分数、完成度、建议 ID、档位 | ≤200 字中文解读 | P1 | W5 |
| 追问回答 | 用户问题 + 当前报告 facts | ≤120 字回答，可反问一次 | P1 | W5 |
| 复测解释 | 两次报告 + 共同维度差值 + 间隔天数 | 一段变化说明 | P1 | W5 |

**不做**：两周计划、理解度复盘、AI 自检、AI 判分、AI 选维度、AI 决定档位、心理疏导、医疗建议、语音/视觉多模态。

## 四、能力边界

| 可做 | 不可做 | 理由 |
| --- | --- | --- |
| 把八维结果改写成中文 | 算分、改分、调权重 | 分数必须同输入同输出 |
| 从固定建议库挑 2–3 条并写“为什么” | 自创新建议 | 无法核实、无法追溯 |
| 解释维度之间的关系 | 判断“你属于哪类人” | 没有常模 |
| 追问时引用 facts、反问澄清 | 回答医疗、用药、诊断类问题 | 非医疗器械定位 |
| 解释复测变化 | 判断“进步/退步”、承诺训练效果 | 没有信效度证据 |

**AI 出错时，错的只能是措辞，不能是分数、结论或建议。**

## 五、架构

| 层 | 产出 | 可复现性 |
| --- | --- | --- |
| L1 计分 | 八维 0–100 参考分 | 严格 |
| L2 规则 | 结论 ID、建议 ID、facts、完成度 | 严格 |
| L3 表达 | 中文解读/追问/复测说明（只引用 L2 facts） | 模板严格；模型版缓存 + 版本冻结 |
| L4 固定块 | 免责声明、局限、生成方式标注 | 硬编码，模型无权改 |
| L5 渲染 | 模板版与 AI 版共用组件 | — |

```text
8 个任务 → L1 计分 → L2 规则 → facts JSON
                                  ↓
                       AI 开关（默认关）
                        ↓ 开              ↓ 关
                  BYOK 模型 → 校验      模板渲染
                        ↓ 失败            ↓
                        └────→ 模板 ←────┘
```

**没有后端、没有网关、没有 server.py。** 请求由浏览器直接发到用户自己配置的 OpenAI-compatible endpoint；Key 只存本机 localStorage。

## 七、BYOK 契约

### 7.1 设置

| 字段 | 说明 |
| --- | --- |
| `endpoint` | OpenAI-compatible `/chat/completions` 地址，必须支持浏览器 CORS |
| `model` | 模型名，由用户填写 |
| `apiKey` | 只存本机 `mindmeter.settings.v1`，不写入导出、不日志 |
| `enabled` | 默认 false；用户主动开启并确认“分数会发送到模型服务” |

> 如果 endpoint 不支持浏览器 CORS，AI 功能不可用；页面提示“请换一个支持 CORS 的 endpoint”，不提供代理服务器。

### 7.2 请求

```json
{
  "model": "user-model",
  "messages": [
    { "role": "system", "content": "你是 MindMeter 的报告解释助手。只解释给定 facts，不算分、不诊断、不新增建议。" },
    { "role": "user", "content": "{\"task\":\"report\",\"dims\":[{\"id\":\"vc\",\"score\":62},{\"id\":\"am\",\"score\":60}],\"completed\":[\"vc\",\"ps\",\"sv\",\"am\"],\"adviceIds\":[\"adv_vc_01\",\"adv_am_02\"],\"retestDelta\":{\"ps\":4},\"constraints\":{\"maxChars\":200}}" }
  ],
  "temperature": 0.3,
  "max_tokens": 400
}
```

**只发**：维度分、完成度、建议 ID、复测差值、档位、约束。
**不发**：姓名、手机号、年龄、学历、学校、公司、原始试次、ASR 文本、API Key 以外的任何凭据。

### 7.3 响应

```json
{
  "headline": "你的空间视觉化相对突出，联想记忆还有提升空间",
  "body": "这次你完成了标准档四项。……",
  "source": "model",
  "degraded": false
}
```

### 7.4 校验

五条核心校验，全过才展示：

1. JSON 结构合法，`headline/body` 都是字符串；
2. 建议 ID 必须在池内，不新增建议；
3. 回答里的数字必须来自 facts；
4. 禁用词命中 0：诊断、治疗、治愈、疗效、正常、异常、提升智商、脑龄、抑郁、痴呆、ADHD；
5. 长度达标：总长 ≤200 字，追问 ≤120 字。

不通过 → 重试一次 → 仍不通过 → 模板。

## 八、追问设计

### 8.1 意图分类（先规则，后模型）

| 类型 | 判别 | 处理 |
| --- | --- | --- |
| 解释类 | 含“为什么/怎么/哪项/什么意思” | 读 facts，生成回答 |
| 澄清类 | 主语缺失、指代不明 | 反问一句，最多一次 |
| 无关 | 闲聊、与测评无关 | 固定回复，引导回报告 |
| 越界 | 病名、药物、诊断 | 拒绝 + 边界说明 + 替代路径 |
| 危机 | 自伤、绝望表述 | **不调模型**，直接给固定资源块 |

### 8.2 上限

- 对话保留最近 3 轮，存 `sessionStorage`，24 小时过期；
- 最多一次反问；
- 单次 ≤8 秒；
- 不调用任何工具；facts 由前端组装。

## 九、复测解释

- 只比较两次都测过的共同维度；
- 显示差值，不判断“进步/退步”；
- 间隔 <7 天时，强制模板提示“练习效应可能影响结果”；
- 档位不同时，只解释共同维度，不比较总分（本来也没有总分）。

## 十、护栏与降级

| 情况 | 处理 |
| --- | --- |
| 未配置 Key / 未开启 | 不发请求，模板 |
| 超时 / 限流 / 空返回 | 模板 |
| 命中禁用词 | 重试一次 → 模板 |
| 数字不在 facts 中 | 模板 |
| 建议 ID 不在池内 | 模板 |
| 断网 | 模板 |
| endpoint 不支持 CORS | 提示换 endpoint，模板 |

**用户永远看不到报错，只看到降级后的内容。报告页永远不空。**

## 十一、隐私

| 项 | 要求 |
| --- | --- |
| 数据出设备 | 仅用户主动开启后，发维度分与 facts |
| 身份信息 | 不发 |
| API Key | 只存本机；可一键清除；公用设备提示 |
| 服务端留存 | 项目组没有服务端；留存由用户选择的模型厂商决定，页面需提示 |
| 关闭 | 随时可关；关闭后模板完整 |

## 十二、验收

1. 关闭 AI 时报告完整；
2. 未配置 Key 时不发任何网络请求；
3. 20 条人工评分：准确、有用、无越界，各 ≥4/5；
4. 禁用词命中 0；
5. 幻觉数字 0（输出数字必须来自 facts）；
6. 单次 ≤8 秒，超时回退；
7. 追问最多一次反问、3 轮；
8. 清除数据后 Key 也被删除；
9. 请求体不含身份/人口学/原始试次/ASR 文本。

## 十三、演示方案（3 分钟）

1. **0:00** 现场完成快测 → 出两项报告，无总分；
2. **0:30** 打开设置，填入一个测试 endpoint/model/key → 开启 AI；
3. **1:00** 生成报告解读 → 看它只引用分数、不新增建议；
4. **1:30** 追问“为什么我联想记忆低” → 看它引用 facts；
5. **2:00** 问一个越界问题（“我是不是有 ADHD”）→ 拒答并给替代路径；
6. **2:20** 断网/关掉 AI → 报告回退模板，仍然完整；
7. **2:40** 收尾：“AI 出错时，影响的是措辞，不是分数。”

**要准备**：一个可用的 OpenAI-compatible endpoint、两条预设分数、断网开关、越界问题一条。

- 两周计划、理解度复盘、生成后自检；
- 语音/视觉多模态；
- AI 判分、AI 选维度、AI 决定档位；
- 服务端代理、serverless 网关、API Key 托管；
- 账号、云端对话存储；
- 认知类型标签。
