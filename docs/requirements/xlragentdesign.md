## 一、一句话

**计分是确定的，AI 负责其余所有"说不清但用户要听"的部分**：解释分数、回答追问、编排两周计划、说明复测变化。它不算分、不改结论、不编数字；模型不可用时模板照常出报告。

## 二、AI 真正不可替代的四处

先回答"为什么非得用 AI"，否则加功能只是堆料。

| 场景 | 模板的极限 | AI 的增量 |
| --- | --- | --- |
| **组合覆盖** | 7 维 × 3 档 × 若干情境 = 数百种写法，模板只能取最常见的几种 | 任意组合都能写，且不重复 |
| **情境适配** | 只能写通用句 | 用户说"最近备考"，建议顺序和措辞跟着变 |
| **追问** | 完全做不到 | 自己去查数据，答不上来会反问 |
| **计划编排** | 只能列固定清单 | 按目标与每周可用时间排出两周计划，并解释理由 |

这四处，模板要么做不到，要么组合爆炸。其余环节（算分、判定、分层）一律不用 AI。

## 三、四个场景

| 场景 | 输入 | 输出 | 优先级 |
| --- | --- | --- | --- |
| 报告解读 | 四/七维分数 + 结论 + 建议池 | 一段解读 + 2–3 条建议 | P0 |
| 复测解释 | 两次报告 + 间隔天数 | 一段变化说明 | P1 |
| 追问回答 | 用户问题 + 当前报告 | ≤120 字回答，可反问澄清 | P1 |
| 两周计划 | 两次报告 + 目标 + 每周可用时间 | 3–5 条计划项 + 理由 | P1 |

**不做**：测评中介入、决定档位与维度、心理疏导、医疗建议。

## 四、能力边界

| 可做 | 不可做 | 理由 |
| --- | --- | --- |
| 把结论改写成中文 | 算分、改分 | 分数必须同输入同输出 |
| 从建议池挑 2–3 条并写"为什么" | 自创新建议 | 无法核实、无法追溯 |
| 解释维度之间的关系 | 判断"你属于哪类人" | 没有常模 |
| 追问时查数据、反问澄清 | 回答医疗、用药、诊断类问题 | 非医疗器械定位 |
| 按时间预算排计划 | 承诺"练两周就能提升" | 没有证据，且违反 BR-05 |

**AI 出错时，错的只能是措辞，不能是分数、结论或建议。**

## 五、架构

| 层 | 产出 | 可复现性 |
| --- | --- | --- |
| L1 计分 | 四维参考分 | 严格 |
| L2 规则 | 结论 ID、建议 ID、facts、可信度 | 严格 |
| L3 表达 | 中文段落、对话、计划（只引用 L2 的 facts） | 模板版严格；模型版缓存 + 版本冻结 |
| L4 固定块 | 免责声明、局限、生成方式标注 | 硬编码，模型无权改 |
| L5 渲染 | 模板版与 AI 版共用组件 | — |

```text
游戏 → L1 计分 → L2 规则 → JSON facts
                              ↓
                   AI 开关（默认关）
                    ↓ 开              ↓ 关
              模型 → 校验         模板渲染
                    ↓ 失败            ↓
                    └────→ 模板 ←────┘
```

**两种形态**：纯静态（默认，模板随代码发布，零请求）；带网关（可选，单个 serverless 函数转发，key 不在前端）。

## 六、功能清单

| ID | 功能 | 内容 | 优先级 | 上线 |
| --- | --- | --- | --- | --- |
| FA-01 | 报告解读 | headline ≤40 字 + 维度句 + 建议理由 | P0 | W4 |
| FA-02 | 维度解释 | 每维一句 ≤90 字，只复述 facts | P0 | W4 |
| FA-03 | 建议推荐 | 从池中选 2–3 条，带 ID 与理由 | P0 | W4 |
| FA-04 | 复测解释 | 说明变化，不判断进步/退步 | P1 | W5 |
| FA-05 | 追问回答 | 意图分类 + 工具查询 + 反问澄清 | **P1** | W5 |
| FA-06 | 状态标注 | "AI 生成·非诊断·可关闭" + 版本号 | P0 | W3 |
| FA-07 | 模板兜底 | 断网/超时/异常时保证报告完整 | P0 | W3 |
| FA-08 | 合规巡检 | 内部扫描诊断化、绝对化表述 | P1 | W5 |
| FA-09 | 两周计划 | 按目标与时间预算排出 3–5 条计划 | P1 | W5 |
| FA-10 | 理解度复盘 | 用户复述，AI 判断是否读懂并纠正 | P1 | W5 |

**FA-01/02/03 是一次调用产出的三块内容**，不拆开。拆开成本×3，三段话还容易互相矛盾。

## 七、工具与契约

| 工具 | 类型 | 返回 | 谁可触发 |
| --- | --- | --- | --- |
| `report.facts.read` | 读 | facts JSON | 用户 |
| `advice.pool.read` | 读 | 建议条目（带 ID） | 用户 |
| `history.read` | 读 | 最近几次摘要 | 用户 |
| `plan.save` | 写 | 保存结果 | 用户，且需幂等键 |

写工具必须：幂等、可撤销、用户可见、不进审计盲区。

**发给模型的全部内容**：

```json
{
  "confidence": "normal",
  "normAvailable": false,
  "dims": [{"id": "wm", "band": "mid", "facts": ["最长正确长度 5", "正确率 63%"]}],
  "allowedAdvice": [{"id": "adv_wm_03", "title": "分组复述练习", "minutes": 10}],
  "constraints": {"adviceCount": [2, 3], "noDiagnosis": true}
}
```

不发原始试次、不发身份信息。

## 八、追问与两周计划的设计

### 8.1 意图分类（先规则，后模型）

| 类型 | 判别 | 处理 |
| --- | --- | --- |
| 解释类 | 含"为什么/怎么/哪项/什么意思" | 走工具查询 |
| 澄清类 | 主语缺失、指代不明 | 反问一句，最多一次 |
| 无关 | 闲聊、与测评无关 | 固定回复，引导回报告 |
| 越界 | 病名、药物、诊断 | 拒绝 + 边界说明 + 替代路径 |
| 危机 | 自伤、绝望表述 | **不调模型**，直接给固定资源块 |

### 8.2 追问流程

```text
问题 → 意图分类
   ├ 澄清 → 反问一句 → 用户补充 → 再分类（最多一次）
   ├ 越界/危机 → 固定话术
   └ 解释 → 读 facts（1 次）→ 需要建议再读池（第 2 次）→ 生成 → 校验
```

上限：工具调用 2 次、对话 3 轮、单次 2 秒。

### 8.3 两周计划

| 项 | 规定 |
| --- | --- |
| 输入 | 两次报告的短板、用户目标（备考/作息/通用）、每周可用时长 |
| 输出 | 3–5 条，每条含：做什么、多久、为什么、对应建议 ID |
| 约束 | 总时长 ≤ 用户预算；覆盖 ≥2 个短板维度；不得承诺效果 |
| 失败 | 超时或不达标 → 输出固定模板计划（3 条） |
| 保存 | 需用户点击确认；重复提交用幂等键去重 |

计划保存是唯一写操作，必须可撤销，并在设置页能看到、能删。

## 九、护栏与降级

**五条核心校验**（全过才采用）：

1. JSON 结构合法；
2. 建议 ID 必须在池内；
3. 回答里的数字必须来自 facts；
4. 禁用词命中 0（诊断/治疗/异常/提升智商/脑龄…）；
5. 长度达标（单句 ≤90 字，总长 ≤200 字）。

**强制走模板的五种情况**：无可信结论、数据不足一维、复测间隔 <7 天、命中危机关键词、模型超时或异常。

| 失败 | 处理 |
| --- | --- |
| 超时 / 乱码 | 模板 |
| 命中禁用词 | 重试一次 → 模板 |
| 断网 | 不调用，直接模板 |

**用户永远看不到报错，只看到降级后的内容。**

## 十、多轮与状态

| 项 | 规定 |
| --- | --- |
| 保留轮数 | 最近 3 轮 |
| 存储 | `sessionStorage`，24 小时过期，可一键清 |
| 默认状态 | 关闭，用户主动开启 |
| 开启提示 | "分数会发送到服务器生成回答，不含身份信息" |

## 十一、安全与合规

- **测评中禁入**：采集结束才开放解读，避免测到"用户 + AI"的联合表现；
- **只读优先**：唯一的写工具是保存计划，且幂等、可撤销；
- **权限在工具层**：不写在提示词里；
- **隐私**：只发聚合分数与 facts，境内模型，可一键关闭；
- **危机**：命中自伤/危机关键词，不调模型，直接给固定资源块。

## 十二、演示方案（3 分钟）

1. **0:00** 现场做一次快测 → 出报告；
2. **0:30** 切"模板版" → 一段通用的话；切回"AI 版" → 同一结论，带着你的情境；
3. **1:00** 连续生成 3 次 → **结论一致、措辞不同**，证明受控生成；
4. **1:30** 问"为什么我抑制控制低" → 现场看它自己查数据、指着数值回答；
5. **2:00** 问一个越界问题（"我是不是有 ADHD"）→ 拒答并给替代路径；
6. **2:20** 点"生成两周计划" → 3–5 条、带时间与理由，可保存、可撤销；
7. **2:40** 关掉 AI 开关 → 报告照常出，只标注"已切换模板"；
8. **2:50** 收尾一句："AI 出错时，影响的是措辞，不是分数。"

**要准备的**：两个预设分数（一高一低）、模板版开关、断网开关、越界问题一条。

## 十三、排期与验收

| 周 | 做什么 | 判定 |
| --- | --- | --- |
| W3 | FA-06、FA-07 | 关掉 AI，报告完整可演示 |
| W4 | FA-01～03 | 24 条用例通过率 ≥95% |
| W5 | FA-04、05、08、09 | 越界 0、禁用词 0、计划合规 |
| W6 | 冻结版本 | 按时演方案走通一遍 |

**创新预算 60 / 30 / 10**：60% 工时投在"必须能演示"的基础（计分、模板、分档）；30% 投在有明确验收的差异化（行为叙事、语音作答、理解度复盘）；10% 留给实验（生成式练习），失败即可砍，不影响交付。

**W3 是闸门**：模板版跑不通，后面的都不做。

**验收**：关闭 AI 报告仍完整 / 禁用词 0 / 幻觉数字 0 / 单次 ≤2 秒 / 测评中无法调用 / 每条回答带尾标 / 计划总时长不超预算。

## 十四、其他候选用法（评估后未纳入）

把所有想到的 AI 用法列出来过一遍，避免"没想到"和"乱加"。

| 用法 | 机制 | 价值 | 成本 | 风险 | 取舍 |
| --- | --- | --- | --- | --- | --- |
| **理解度复盘** | 让用户用自己的话复述报告，AI 判断是否理解、指出偏差 | 高：直接对应验收"能说出最低维度" | 低 | 低 | ✅ 加入（W5，P1） |
| **生成后自检** | 同一模型再审一遍：有没有越界、有没有编数字 | 中：多一道保险 | 低 | 低 | ✅ 加入（第 6 道校验） |
| **构建期出题** | 生成干扰词、旋转图形、练习素材 | 中：省人工 | 低 | 低 | ✅ 内部使用，不进产品 |
| 差异归因 | 复测差异的三种解释（状态 / 练习 / 噪声）排序 | 中 | 低 | 中 | ⚪ 并入 FA-04 |
| 语音读题 / 读报告 | TTS 无障碍 | 中 | 低 | 低 | ⚪ 可选 |
| 个人"认知使用手册" | 生成"你适合什么时候做难任务" | 高（卖点） | 低 | **高**：无依据，近伪科学 | ❌ 不做 |
| 多模型交叉校验 | 两个模型比对结论 | 低 | 高 | 低 | ❌ 成本不值 |
| AI 扮演主试 | 语音引导施测 | 中 | 中 | **高**：影响标准化 | ❌ 不做 |

### 14.1 理解度复盘（建议加入）

| 项 | 内容 |
| --- | --- |
| 目标 | 确认用户真的看懂了报告，而不是看到一堆分数 |
| 做法 | 报告页问一句"你觉得哪项最需要练？"→ AI 判断是否与最低维度一致 |
| 输出 | 一句反馈：对了就确认，错了就指出并解释 |
| 价值 | 这是**唯一能自动验证"报告是否被读懂"的功能**，可直接作为用户测试工具 |
| 风险 | 低，不涉及结论生成 |

### 14.2 生成后自检（建议加入）

在 5 条核心校验之后，再加一道模型自检：

```text
请检查下面这段报告：
1. 有没有出现诊断、治疗、疗效类表述？
2. 有没有出现输入数据里不存在的数字？
3. 有没有把"状态"说成"能力"？
只回答"通过"或指出问题。
```

自检不过 → 直接走模板。这一条几乎零成本，答辩时可以说"我们的 AI 会审自己的稿"。

## 十五、不做的

- 评测修复 Agent（开发侧工具，不是产品功能）；
- AI 自适应难度（破坏复测可比性）；
- 语音 / 视觉多模态；
- 认知类型标签（没有常模）。
