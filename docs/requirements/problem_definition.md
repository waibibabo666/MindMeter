二、阅读说明

 MindMeter 不是医疗器械，不提供临床诊断或治疗建议；该边界贯穿全部产品设计。


三、文档目的与范围

本文是 MindMeter 的立项基线，用于对齐团队对用户、问题、价值与边界的理解，并为后续功能规范、非功能规范提供上游依据。
范围内：面向普通消费者的心智测评与成长追踪产品，Web优先，包含测评、报告、历史趋势、建议与基础账号体系。
范围外：临床诊断、治疗、药物建议、危机干预、心理咨询师撮合平台、面向企业的完整HR系统。本期不做，后续评估。

四、执行摘要

普通人越来越愿意为了更了解自己投入时间，但现有工具呈两极化：娱乐化人格测试传播强、可信度弱；专业心理量表门槛高、解释成本高、复测与追踪弱。MindMeter 的机会在于把心理测量学的可信度与消费级产品的低门槛、可解释、可追踪结合起来。产品以5至10分钟的轻量认知任务与自评量表采集数据，由 Core Engine 完成计分、效度校验与常模映射，输出多维心智画像、可信度提示与行动建议；用户可定期复测，查看趋势。

五、5W1H

MindMeter 面向18岁以上希望了解自身注意力、情绪调节、决策方式和记忆状态、但不愿被贴上病人标签的自我提升人群，优先职场人和大学生，因为现有娱乐测试不可信、专业量表门槛高且缺少追踪；我们做一个 Web 优先的在线心智测评与成长追踪产品，用5至10分钟轻量任务和自评量表生成多维画像、可信度提示和行动建议，支持复测趋势；计划用约6周完成分析、设计、开发、测试和发布，由四人小团队协作，通过内容平台和机构合作获客，数据存境内，坚持隐私优先，不做临床诊断。

六、产品描述

7.1 产品定位陈述
对于希望了解自身心智状态、但不愿被贴上病人标签的18岁以上自我提升人群，他们在注意力、情绪调节、决策方式与记忆上反复受挫，却缺少可信、低门槛、可解释、可追踪的自评工具。MindMeter 是一个在线心智测评与成长追踪产品，它能够用5至10分钟的轻量任务与量表，生成多维心智画像、可信度提示与行动建议，并支持定期复测与趋势对比。不同于娱乐化人格测试、单次专业问卷和纯训练类应用，我们的产品以心理测量学为基础，提供效度控制、本土常模、纵向趋势与隐私优先的数据设计。
7.2 使命
让每个人都能以可信、可理解、可行动的方式看见自己的心智状态，并持续获得成长反馈。
边界：使命止于理解与成长，不承诺诊断、治疗或治愈。
7.3 口号
看见心智，量出成长。
