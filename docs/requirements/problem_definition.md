## 1. 文档目的与范围

本文是 MindMeter 的立项基线，用于：

1. 对齐团队对用户、问题、价值与边界的理解；
2. 为功能规范（MM-REQ-002）与非功能规范（MM-REQ-003）提供上游依据；
3. 作为里程碑评审、范围变更与优先级取舍的判断标准。

**范围内**：面向普通消费者的心智测评与成长追踪产品（Web 优先），包含测评、报告、历史趋势、建议与基础账号体系。

**范围外**：临床诊断、治疗、药物建议、危机干预、心理咨询师撮合平台、面向企业的完整 HR 系统（本期不做，后续评估）。

## 2. 执行摘要

普通人越来越愿意为「更了解自己」投入时间与金钱，但现有工具呈两极化：一端是娱乐化人格测试，传播强、可信度弱；另一端是专业心理量表，门槛高、解释成本高、复测与追踪弱。MindMeter 的机会在于把**心理测量学的可信度**与**消费级产品的低门槛、可解释、可追踪**结合起来。

产品以 15–20 分钟的轻量认知任务与自评量表采集数据，由 Core Engine 完成计分、效度校验与常模映射，输出多维心智画像、可信度提示与行动建议；用户可定期复测，查看趋势。商业模式采用免费基础测评 + 付费完整报告/订阅，后续拓展学校、企业与教练机构（B2B/B2B2C）。

**当前最关键的三个未决问题**：

1. 首批测量维度与量表来源是否具备科学性与合法授权（D-01/D-02）？
2. 目标用户是否愿意为「可信的心智报告」持续付费（A-01/A-03）？
3. 15–20 分钟且带效度控制的测评，完成率能否支撑增长（A-04）？

## 3. 5W1H 报告

### 3.1 Why：为什么做

#### 3.1.1 背景

- 心理健康与自我提升从「小众话题」变为日常议题，但大众市场仍被娱乐化测试占据。
- 可穿戴设备与自我量化培养了「用数据了解自己」的习惯，心智层面却缺少同等易用的工具。
- 专业量表多用于科研或临床，普通人难以获得、难以读懂，更难以看到长期变化。
- AI 与自适应测评（CAT）降低了「少题目、高精度」的实现成本，使科学测评具备消费级体验的可能。

#### 3.1.2 问题陈述

> 希望了解自己心智状态的普通人，在注意力、情绪调节、决策方式与记忆等方面反复受挫，却缺少一个**可信、低门槛、可解释、可追踪**的自评工具；他们要么得到娱乐化的标签，要么面对看不懂的专业分数，最终无法把「了解自己」转化为「改变自己」。

#### 3.1.3 问题带来的代价

| 代价 | 表现 | 影响 |
| --- | --- | --- |
| 认知成本 | 不知道哪个测评可信，反复做免费测试 | 时间浪费、结论互相矛盾 |
| 情绪成本 | 被标签化、被贩卖焦虑 | 自我否定、对心理测评失去信任 |
| 决策成本 | 想改善却不知道从哪开始 | 训练/咨询投入低效 |
| 机会成本 | 早期状态变化未被识别 | 问题加重后才求助，成本更高 |
| 信任成本 | 数据隐私担忧 | 不愿如实作答，结果失真 |

#### 3.1.4 机会窗口

- 需求侧：自我探索、情绪管理、职场压力与「脑力管理」内容消费增长。
- 供给侧：传统测评数字化程度低；训练类产品缺少可信测量；两者之间存在「测量 + 追踪 + 建议」的空位。
- 技术侧：CAT/IRT、可解释报告生成、隐私计算与端侧处理逐步成熟。
- 渠道侧：内容平台使「测评 + 科普 + 分享」形成低成本获客闭环。

**待验证**：上述判断目前基于团队观察与公开资料，需通过用户访谈（N=【待定】）、竞品拆解与搜索趋势数据验证；市场规模的测算口径见 §4.4.3。

### 3.2 What：做什么

#### 3.2.1 产品定义

MindMeter 是一个**在线心智测评与成长追踪产品**：用标准化任务与量表测量多维心智状态，生成可解释的报告，帮助用户理解当前状态、识别变化，并获得下一步行动建议。

#### 3.2.2 MVP 范围

| 包含 | 不包含（本期） |
| --- | --- |
| 1 套核心测评（15–20 分钟，4 个维度以内） | 多套垂直测评矩阵 |
| 知情同意、环境检查、断点续答 | 临床量表与诊断报告 |
| 自动计分、效度校验、常模百分位 | 自适应测评（CAT，v1.1 评估） |
| 多维画像 + 可信度提示 + 行动建议 | AI 对话式深度解读 |
| 账号、历史记录、趋势对比 | 社区、排行榜、UGC |
| 分享卡片（隐私可控） | 训练课程商城 |
| 运营后台（题库、版本、看板） | 企业级组织管理与席位计费 |

#### 3.2.3 交付物

- 可用的 Web 产品（移动端优先）；
- 测评内容包：题目、计分键、常模说明、报告文案；
- 算法与计分说明、效度证据文档；
- 隐私政策、用户协议、知情同意书、免责声明；
- 运营后台与基础数据看板；
- 本文档及功能/非功能/管理文档基线。

### 3.6 How：怎么做

#### 3.6.1 解决方案路径

```text
内容/分享获客
   ↓
免费基础测评（知情同意 → 环境检查 → 任务/量表 → 效度校验）
   ↓
多维报告（分数 + 百分位 + 可信度 + 解释 + 建议）
   ↓
注册保存 → 历史趋势 → 复测提醒 → 付费完整报告/订阅
   ↓
数据反馈 → 优化题目/常模/文案 → 提升完成率与留存
```

#### 3.6.2 科学性方案

- 测量框架：CTT 为主，逐步引入 IRT/CAT；首版固定题本，控制复杂度。
- 质量控制：正反向题、重复题、反应时、随机作答检测；低可信结果明确提示，不输出确定性结论。
- 常模：建立分层常模（年龄/性别/教育等，按伦理与必要性取舍），公开样本来源与局限。
- 报告：分数必须带置信区间/百分位，避免「高低好坏」的绝对化标签；建议需可执行、可验证。
- 伦理：知情同意、退出自由、结果解释边界、危机资源指引、数据最小化。

详见[算法设计](../algorithm.md)与功能规范 FR-300 系列。

#### 3.6.3 技术方案（待定）

- 前端：响应式 Web，测评任务需稳定计时与低延迟输入；
- 后端：账号、会话状态机、报告、订阅、后台；
- Core Engine：计分、效度、常模、版本管理；
- 数据：PostgreSQL + Redis + 对象存储（建议）；
- 部署：云托管、自动化 CI/CD、监控告警、备份恢复。

技术选型与架构决策见[软件设计](../software.md)。

### 4.2 使命

> 让每个人都能以可信、可理解、可行动的方式看见自己的心智状态，并持续获得成长反馈。

**边界**：使命止于「理解与成长」，不承诺诊断、治疗或治愈。

### 4.4 产品策略

#### 4.4.1 目标用户是？

首版聚焦 **P1 自我提升型职场人 + P2 大学生/研究生**：他们有主动探索意愿、线上付费习惯（或潜在付费意愿）、对「可信」敏感，且可通过内容平台低成本触达。P3 助人者作为 B2B 切入口，P4 泛健康人群在验证报告可读性后拓展。

选择理由：

- 需求频率适中：不需要每天使用，但会在换工作、考试、年初等节点复测；
- 支付意愿分层清晰：P1 为效率与确定性付费，P2 为低门槛与社交分享付费；
- 传播性强：报告与分享卡片天然适合内容平台；
- 风险可控：避开临床人群，降低合规与伦理风险。

**待验证**：优先服务 P1 还是 P2，需在访谈与落地页测试后确定（D-04）。

**组合策略**：

- **WO**：借高校/咨询机构合作补足背书与常模样本，换取早期用户。
- **ST**：以纵向数据与效度控制构建难复制壁垒；坚持合规，避免与灰色引流产品同质化。
- **WT**：控制范围与成本，先做单点高价值场景；建立隐私与危机事件预案，避免一次性信任崩塌。

#### 5）解决方案 + 类似产品 + 差异化

**解决方案**：

1. 轻量测评：15–20 分钟，认知任务 + 自评量表，支持断点续答；
2. 可信计分：效度校验 + 常模百分位 + 置信区间；
3. 可解释报告：多维画像、状态解读、局限说明、行动建议；
4. 纵向追踪：历史对比、复测提醒、变化归因提示；
5. 隐私可控：最小化采集、可见性设置、导出与删除。

**类似产品**：娱乐化人格测试、专业心理测评平台、认知训练 App、情绪记录 App。

**差异化**：科学可信 × 消费级体验 × 纵向追踪 × 隐私优先；不与娱乐测试比传播，不与临床平台比诊断，而以「可信的自我认知工具」占据中间空位。详见 §4.4.4。
