# Tests

## 分层

| 目录 | 范围 | 例子 |
| --- | --- | --- |
| `unit/` | 计分公式、工具函数 | 工作记忆 0/满/中间值；缺失数据；反应时边界 |
| `integration/` | 完整流程 | 完成 4 个游戏 → 出报告 → 写入本地 → 历史可读 |

## 工具

W2 确定技术栈后补充（可选 Vitest、Jest、Playwright）。当前只保留目录结构。

## 测试数据

- 只用合成数据，不提交真实用户作答；
- 固定输入和期望输出，保证可复现；
- 每个公式至少覆盖正常、边界、缺失三类用例。

## 验收底线

- 4 个游戏都能完整跑通；
- 报告分数与手算结果一致；
- 刷新后已完成游戏不丢；
- 手机端核心流程无阻断。
