# 测试

测试分层与质量门槛的落地说明。具体命令待各模块实现后补充。

## 测试分层

| 层级 | 范围 | 工具（待定） | 要求 |
| --- | --- | --- | --- |
| 单元测试 | 计分、效度规则、工具函数 | pytest / Vitest | 核心计分覆盖率 ≥ 80%，整体 ≥ 60% |
| 集成测试 | API + 数据库 + core_engine | pytest / Supertest | 覆盖会话状态机、权限、数据删除 |
| 端到端测试 | 关键用户旅程 | Playwright | 首次测评、断点续答、报告、注销 |
| 非功能测试 | 性能、安全、无障碍 | k6 / OWASP ZAP / axe | 达到 NFR 门槛 |
| 人工验收 | 科学性与可读性 | 评审清单 | 心理测量顾问签字 |

## 测试数据

- 只使用合成或脱敏数据；禁止把真实用户作答提交到仓库。
- 固定随机种子，保证可复现。
- 涉及常模的测试使用小型公开/合成样本，并在用例中注明来源与限制。

## 质量门槛

发布前必须满足 [非功能需求规范](../docs/requirements/nonfunctional_spec.md) 中的发布门禁：P0 用例全通过、无阻断/严重缺陷、安全与隐私检查通过、无障碍关键路径通过。
