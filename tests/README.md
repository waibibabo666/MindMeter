# Tests（L2）

## 分层

| 目录/类型 | 范围 | 例子 |
| --- | --- | --- |
| `unit/` | 8 个计分公式、校验、RAG 检索、JWT/密码 | 正常/边界/缺失；禁用词；数字来源 |
| `integration/` | 注册→测评→计分→报告→对话→记忆→趋势 | 服务端计分幂等；删除后不引用 |
| `e2e/` | 浏览器关键路径 | 登录、测评、对话、ASR 失败、导出/注销 |
| `ai_eval/` | 30 条 Agent + 20 条 RAG | 准确/有依据/有用/无越界；hit@3 |

## 工具

- 后端：`pytest` + `httpx` + 测试数据库；
- 前端：Playwright（M2 起）；
- 代码质量：ruff/mypy（Python）、eslint（JS，按需）。

## 测试数据

- 只用合成数据，不提交真实用户作答/对话；
- 固定输入/期望输出；计分金标准用例；
- AI 评测集固定版本，改动需评审；
- 明确断言：不产生总分/均分/百分位；未测维度为 `null`。

## 验收底线

- 注册→标准 4 项→报告→对话→记忆→复测→趋势跑通；
- 服务端计分与金标准一致；重复提交幂等；
- 无总分/常模/百分位；未测显示“未测”；
- AI 失败回退模板；禁用词 0；幻觉数字 0；
- 删除账号 30 天内清除；导出不含 Key；
- 备份恢复至少 1 次。
