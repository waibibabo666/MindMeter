# Tests

## 分层

| 目录 | 范围 | 例子 |
| --- | --- | --- |
| `unit/` | 8 个计分公式、工具函数 | 言语理解 0/满/中间值；联想记忆 d′；空间视觉化异常 RT；缺失数据 |
| `integration/` | 三档完整流程 | 快测 2 项 / 标准 4 项 / 深度 8 项 → 八维报告 → 写入本地 → 历史可读 |

## 工具

原生 `node:test`；不引入构建链。W2 确定目录后补充运行命令。

## 测试数据

- 只用合成数据，不提交真实用户作答；
- 固定输入和期望输出，保证可复现；
- 每个公式至少覆盖正常、边界、缺失三类用例；
- 明确断言：**不产生总分/均分**；未测维度为 `null`。

## 验收底线

- 8 个任务都能独立完成；
- 三档总时长在 5 / 13 / 28 分钟目标内（允许 ±20%）；
- 报告分数与手算结果一致；未测显示“未测”；
- 刷新后已完成任务不丢，当前任务从说明页重开；
- 关闭 AI 报告完整；ASR 失败有提示；
- 手机端核心流程无阻断。
