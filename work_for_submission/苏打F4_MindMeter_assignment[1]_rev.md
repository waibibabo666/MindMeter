# MindMeter 产品设计（作业 1）

> 课程提交版（2026-11-28 修订，对齐当前 L2 实现：Web 应用 + 账号 + 服务端 Agent + 记忆 + RAG + 服务端计分）。
> 产品与需求细节见 [docs/README.md](../docs/README.md) 与 [docs/requirements](../docs/requirements/)。

## 产品使命

在信息轰炸的时代，我们的大脑能力并不一定总是在提高。
让每个人用几局游戏的时间，看清自己的能力结构、短板在哪里、下一步该怎么练。

## 产品口号

**玩一局，看清你的大脑；聊一次，知道下一步。**

## 目标用户

| 层级 | 人群 | 说明 |
| --- | --- | --- |
| **核心（首发）** | 18–30 岁大学生、职场新人 | 传播强、合规压力小，首发主攻 |
| 扩展 | 25–40 岁白领 | 效率焦虑、脑力疲劳，二期考虑 |
| 高价值 | 45–65 岁中老年及子女 | 付费意愿高，二期考虑 |
| B 端 | 学校、企业 HR、体检机构 | 客单价高、周期长，本期不做 |

> 本期不做 B 端、不做付费；深度档不收费。

## 如何获得目标用户

总体思路：**内容种草 → 站内体验 → 复测留存**。先不发付费广告、不做裂变拉新，用低成本内容验证「内容—注册—完测—复测」这条漏斗，再决定是否加投放。

### 1. 渠道与内容

| 平台 | 内容形式 | 频率 | 作用 | 转化路径 |
| --- | --- | --- | --- | --- |
| 小红书 | 图文测评体验、维度科普、复测前后对比 | 每周 2–3 篇 | 触达 18–30 岁学生与职场新人 | 笔记 → 主页链接/二维码 → 注册 → 快测（6 分钟） |
| B 站 | 3–5 分钟产品演示、开发日志、认知科普 | 每两周 1 条 | 建立可信度、沉淀长尾搜索 | 视频简介/置顶评论 → 站点 → 标准测评（12 分钟） |
| 抖音 | 15–60 秒「测一测」切片、结果解读片段 | 每周 3–4 条 | 拉新与话题曝光 | 视频 → 评论区/主页 → 注册 |
| 校园与社群 | 社团合作、课程演示、线下海报 | 按学期 | 冷启动种子用户 | 现场扫码 → 注册 → 完测 → 收集反馈 |

### 2. 内容选题（示例）

- 反常识选题：「为什么我们不做总分」「分数低不等于能力差」
- 场景选题：考试周、求职季、长期熬夜后的状态自查
- 复测选题：「隔两周再测，我发现了什么」「练习效应是什么」
- 方法选题：联想记忆怎么练、言语流畅怎么练（对应知识库 `plan` 类内容）

### 3. 转化漏斗与验证指标

| 环节 | 指标 | 首月目标（小样本验证） |
| --- | --- | --- |
| 曝光 → 点击 | 主页/链接点击率 | ≥ 2% |
| 点击 → 注册 | 注册转化率 | ≥ 15% |
| 注册 → 完测 | 完成一次标准测评 | ≥ 40% |
| 完测 → 复测 | 7 日内再次测评 | ≥ 15% |

> 指标用于判断内容方向，不作为对外承诺；未达标时先改内容与落地页，不急着加投放。

### 4. 冷启动顺序

1. 课程演示与社团合作拿种子用户与真实反馈；
2. 小红书图文验证选题与文案（成本最低、迭代最快）；
3. B 站长视频沉淀可信度与搜索长尾；
4. 抖音切片放量，把验证过的选题做成短视频；
5. 建立「每周内容复盘」，把高转化选题沉淀为模板。

### 5. 合规与边界

- 只做**内容分享与产品演示**，不做医疗、疗效或「提升智商」类宣传；
- 明确 18+、非诊断、无常模、不设总分；不制造焦虑、不承诺训练效果；
- 内容中不出现用户真实结果截图（除非用户书面同意并脱敏）；
- 平台对「心理测评」内容审核较严：小红书/抖音文案避免「诊断」「治疗」「测试你的心理疾病」等表述，改为「认知自测」「能力画像」。

## 产品策略

| 问题 | 答案 |
| --- | --- |
| 如何争取用户 | 内容种草（小红书/B 站/抖音）→ 课程与社团演示 → 口碑传播；不做付费投放、不做裂变拉新 |
| 团队优势 | 4 人小团队，产品/前端/后端与计分/测试与评测分工明确；8 项多维画像 + 三档按需；测—评—建议—复测闭环 |
| 差异化 | 不设总分、没有常模、不假装临床；用 6–18 分钟给出可解释的八维画像和可执行建议 |

| 给出可执行建议 | ❌ | ❌ | ❌ | ✅ |
| 测—评—复测闭环 | ✅ | ✅ | ❌ | ✅ |

> 常模和临床效度明确写“本期不做/不宣称”，不标“建设中”，避免被理解成已有能力。

## 8 项能力

言语理解、言语流畅性、数字运算、知觉速度、归纳推理、空间视觉化、联想记忆、自然探索。

> 8 项是产品口径，不是学界公认的“8 种智力”；本期不测工作记忆、抑制控制、认知灵活性。报告会写明这些边界。
