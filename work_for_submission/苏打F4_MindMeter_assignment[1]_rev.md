## 产品使命

在信息轰炸的时代，我们的大脑认知水平并不一定总是在提高
让每个人花 15 分钟玩几局游戏，就能看清自己的认知能力处在什么水平、短板在哪里、下一步该怎么练。

## 产品口号

**玩一局，看清你的大脑** —— 测得出，也练得进。

## 目标用户

| 层级 | 人群 | 说明 |
| --- | --- | --- |
| **核心（首发）** | 18–30 岁大学生、职场新人 | 传播强、合规压力小，首发主攻 |
| 扩展 | 25–40 岁白领 | 效率焦虑、脑力疲劳 |
| 高价值 | 45–65 岁中老年及子女 | 付费意愿高，二期进入 |
| B 端 | 学校、企业 HR、养老与体检机构 | 客单价高，销售周期长 |

## 产品策略

| 问题 | 答案 |
| --- | --- |
| 如何争取用户 | 报告可分享（社交货币）→ 场景化切入（考试周、求职季）→ 校园渠道 → 数据背书做 PR |
| 团队优势 | 认知科学 + 游戏设计 + 算法工程的交叉能力；数据飞轮；小团队迭代快 |
| 差异化 | 测—评—练—复测闭环，不做"只打分"的生意 |
