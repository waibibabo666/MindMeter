# MindMeter 产品定义（作业 2）

> 课程提交版（2026-11-28 修订，对齐当前 L2 实现：Web 应用 + 账号 + 服务端 Agent + 记忆 + RAG + 服务端计分）。
> 产品与需求细节见 [docs/README.md](../docs/README.md) 与 [docs/requirements](../docs/requirements/)。

## 产品定位

> **对于** 18–30 岁、想了解并提升自己认知状态的大学生与职场新人，
> **他们** 只能靠主观感觉判断自己的强项和短板，或去做又贵又慢的专业测评，
> **MindMeter** 是一个**面向普通人的 Web 认知自测与解读产品**，
> **它能够** 用 6–18 分钟给出可视化的八维画像、可执行建议，并由对话式 Agent 解释结果、回看变化，
> **不同于** 只给一个分数的脑力 App，也不同于门槛高昂的临床量表，
> **我们的产品** 把「测—评—建议—复测」做成闭环，且**不设总分、没有常模、非诊断**。

## 作品形式

**Web 应用**：浏览器直接访问，无需下载安装；桌面与手机同一套页面（360px 起自适应）。

| 维度 | 说明 |
| --- | --- |
| 形态 | Web 应用（B/S 架构）；FastAPI 同源托管 `/api/v1/*` 与前端静态文件 |
| 入口 | 注册 / 登录 → 选档位 → 测评 → 八维报告 → 对话 → 记忆 → 复测 |
| 账号 | 用户名 + 密码（PBKDF2-SHA256），HttpOnly + SameSite=Lax 会话 Cookie，数据按账号隔离 |
| 数据 | 服务端 PostgreSQL + pgvector；导出 JSON 不含密钥；删除账号即清理 |
| AI | 站点统一模型（无需用户自备 Key）；LangGraph 编排；模型不可用自动回退模板 |
| 部署 | Docker 单容器 + nginx 反向代理（云服务器），或 Railway 托管 |
| 端 | 浏览器即可；不提供桌面客户端、小程序或 App（本期不做） |

> 历史说明：早期桌面版（pywebview + 本地 PostgreSQL + 用户自备 Key）已移除，当前为托管 Web 版。

## 产品定义

| 项目 | 内容 |
| --- | --- |
| 产品名称 | MindMeter（心智镜） |
| 形态 | Web 应用（浏览器访问，注册即用） |
| 目标用户 | 18–30 岁大学生与职场新人 |
| 核心问题 | 认知状态看不见、测不了、测了也不知道下一步做什么 |
| 解决方案 | 8 项能力任务 + 快测/标准/精细三档 + 八维画像 + 对话式解释 + 建议 + 纵向复测 |
| 测量口径 | 0–100 参考分（`scoring-v3.3`）；不设总分；没有常模、不做百分位；非临床 |
| 三档 | 快测 ≈6 分钟；标准 ≈12 分钟；精细 ≈18 分钟（均为 8 项，题量与限时不同） |
| 记忆 | 画像（需确认）、测评摘要、建议记录、最近 20 条对话 |
| 趋势 | 两次以上复测只比共同维度，提示练习效应，不判断进步/退步 |
| 护栏 | 危机/越界固定话术；禁用词；数字白名单；引用；模板兜底 |
| 里程碑 | 分析 → 设计 → 开发 → 测试 → 发布 → 迭代 |
| 团队 | waibibabo666（项目）、xlr268（产品）、song / 1213lz（技术） |

> 本期不做：B 端、支付、常模、总分、百分位；不测工作记忆、抑制控制、认知灵活性。
