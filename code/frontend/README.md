# Frontend

负责首页、知情同意、4 个游戏、报告、历史记录和数据清除。

## 页面

| 页面 | 作用 |
| --- | --- |
| 首页 | 产品说明、预计时长、开始按钮 |
| 同意页 | 18+ 确认、隐私提示、非诊断声明 |
| 游戏页 | 说明 → 练习 → 正式试次，共 4 个游戏 |
| 报告页 | 四维雷达图、分数、解释、建议、局限 |
| 历史页 | 本地记录、复测对比、清除数据 |

## 计划目录

```text
frontend/
├─ index.html
├─ src/
│  ├─ main.js          # 入口与页面切换
│  ├─ pages/           # 首页、同意、报告、历史
│  ├─ games/           # 4 个游戏
│  ├─ components/      # 进度条、雷达图、卡片
│  ├─ lib/storage.js   # localStorage 读写
│  └─ styles/
└─ README.md
```

## 约定

- 页面不写计分公式，统一调用 `core_engine`；
- 每局结束立即写入 localStorage，避免刷新丢结果；
- 手机端 360px 起可用，按钮不小于 44×44px；
- 不收集姓名、手机号等身份信息，不接第三方广告/统计。

## 启动

技术栈 W2 确认后补充。若采用纯静态方案，直接用浏览器打开 `index.html`；若采用 Vite，补充 `npm install` / `npm run dev`。
