# Frontend（Web 客户端）

面向用户的测评与报告界面，移动端优先、桌面端可用。

## 职责边界

- 测评引导、知情同意、环境检查、任务呈现与作答采集。
- 报告可视化、趋势对比、建议与分享卡片。
- 无障碍、低端设备与弱网适配。
- 不在客户端做最终计分；仅做展示层校验与必要的离线缓存。

## 目录约定（待实现）

```text
frontend/
├─ src/
│  ├─ pages/        # 路由页面
│  ├─ components/   # 通用组件
│  ├─ features/     # 测评、报告、账号等领域模块
│  ├─ lib/          # API 客户端、埋点、工具
│  └─ styles/       # 设计令牌与全局样式
├─ public/
└─ tests/
```

## 体验与无障碍要求

- 移动端 360px 起可用；关键操作单手可完成。
- 键盘可完成全流程；对比度 ≥ 4.5:1；支持减少动效。
- 测评计时相关交互必须给出明确进度与退出确认。
