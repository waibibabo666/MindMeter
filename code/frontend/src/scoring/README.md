# 本地计分 scoring-v3.1（L-02）

把任务上报的原始指标，转成 0–100 的参考分。**不产生总分**。

8 个维度的公式全部实现；M1 的壳只做了 4 个任务，所以实际只会产出 4 个分数，
其余 4 个为 `null`（显示为「未测」）。

对应 Issue [#38](https://github.com/waibibabo666/MindMeter/issues/38)、[m1_scope.md](../../../../docs/mgmt/m1_scope.md) 的 L-02。

## 为什么是 v3.1 而不是直接照抄 algorithm.md

`algorithm.md`（v4.0）的公式基于 **vc 15 题、ps 60 秒、sv 20 题、am 12+12**，
但 `data.js` 里实际实现的是 **vc 6 题、ps 45 秒、sv 8 题、am 12 组 + 16 题（8 旧 + 8 新）**。

照抄公式的后果（实测）：

| 作答        | 文档公式  | 按实际题量 |
| ----------- | --------- | ---------- |
| vc 全对 6/6 | **40 分** | 100 分     |
| vc 对 4/6   | 27 分     | 67 分      |

所以本版把分母与锚点改到实际题量上，并在 `config.js` 集中管理，
**以后校准只改 config，不改公式代码**。

## 接口

```js
import { scoreSession } from './scoring/index.js';

const result = scoreSession(store.results);
// {
//   version: 'scoring-v3.1',
//   dimensions: { vc: 67, vf: null, nc: null, ps: 38, ir: null, sv: 70, am: 44, ni: null },
//   measured: ['vc', 'ps', 'sv', 'am'],
//   missing:  ['vf', 'nc', 'ir', 'ni'],
// }
```

**返回值里没有 `total` / `mean` / `composite`** —— M1 不设总分，结构上就不给这个字段。

## 公式

| 维度          | 公式                                         | 阈值                                            |
| ------------- | -------------------------------------------- | ----------------------------------------------- |
| vc 言语理解   | `round(100 × correct / total)`               | 6 题；完成 <80% → null                          |
| ps 知觉速度   | `round(100 × clamp01((correct − 8) / 16))`   | 45 秒；8 个 → 0，24 个 → 100                    |
| sv 空间视觉化 | `round(100 × (0.7 × 正确率 + 0.3 × RT得分))` | 8 题；RT 1500ms → 1，4000ms → 0；正确 <4 → null |
| am 联想记忆   | `round(100 × clamp01((d′ + 1) / 5))`         | targets 8、foils 8；d′ = −1 → 0，4 → 100        |

`d′ = z(H) − z(F)`，其中 `H = (hits + 0.5) / (targets + 1)`、`F = (falseAlarms + 0.5) / (foils + 1)`。

其余四个维度（vf / nc / ir / ni）M1 不测，恒为 `null`。

## 缺失规则

| 情况                          | 结果               |
| ----------------------------- | ------------------ |
| 任务未做 / 本档未包含         | `null`             |
| 固定题量任务完成率 <80%       | `null`             |
| sv 正确试次 <4                | `null`             |
| sv 反应时 <200ms 或 >3×中位数 | 剔除后再算中位数   |
| 一题没对                      | `0`（不是 `null`） |

```bash
node scripts/test_scoring.js
```

14 条检查：4 组金标准 + 6 条缺失/边界 + 结构约束 + 复现 + 性能（1000 次 <100ms，实测约 6ms）。

## 已知约定

- 取整统一用 `Math.round(100 × x + 1e-9)`，避免 70.5 被浮点算成 70.4999 后向下取整；
- `am` 的 targets/foils 优先从 `answers` 里数，保证再认题因去重变少时仍然正确；
- 计分是纯函数：同样输入 + 同样 config 必然得到同样输出。

## 八个维度

| 维度          | 公式                                      | 说明                                                |
| ------------- | ----------------------------------------- | --------------------------------------------------- |
| vc 言语理解   | `100 × correct / total`                   | 固定 6 题，完成率 <80% 记 null                      |
| vf 言语流畅性 | `100 × clamp01((validCount − 10) / 20)`   | 10 个有效词 → 0，30 个 → 100                        |
| nc 数字运算   | `100 × correct / total`                   | 固定 20 题                                          |
| ps 知觉速度   | `100 × clamp01((correct − 8) / 16)`       | 45 秒，8 个 → 0，24 个 → 100                        |
| ir 归纳推理   | `100 × correct / total`                   | 固定 15 题                                          |
| sv 空间视觉化 | `100 × (0.7 × 正确率 + 0.3 × 反应时得分)` | 反应时 1500ms → 满分，4000ms → 0；正确数 <4 记 null |
| am 联想记忆   | `100 × clamp01((d′ + 1) / 5)`             | d′ = z(H) − z(F)，H/F 各做 +0.5/+1 校正             |
| ni 自然探索   | `100 × correct / total`                   | 固定 20 题                                          |

固定题量类（vc/nc/ir/ni）都会做「完成率 <80% → null」的检查；
限时类（ps）与流畅性（vf）没有完成率概念，不做该检查。
